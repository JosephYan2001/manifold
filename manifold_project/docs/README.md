# 文档导航

项目采用 CTDE 本地方向学习理论。研究文档只保留以下三份主体：

| 文档 | 负责内容 |
|---|---|
| [理论主稿](策略流形研究设计.CTDE本地策略改进版.md) | 数学对象、命题、证明及适用条件 |
| [实验方案](策略流形研究设计.实验方案.md) | 研究问题与实验组对应、每个环境的职责、缺失保证、比较规则和实施顺序 |
| [项目总体架构](项目总体架构.md) | 任务、数据、算法、运行与评价的边界，以及代码迁移和验收 |

先读实验方案了解当前研究，再按需要查理论或架构。下一步任务统一在实验方案第 12 节维护。

现有代码、命令和数据入口见[实验目录](../experiments/README.md)。成对与导航各保留 README、实现说明、实验运行说明；环境说明只解释真实接口，不另建研究计划。

研究方案、已实现行为和验收证据分别标明。正式参数以验收后的有效配置为准；文档中的示例、现有兼容配置和历史数据不自动成为新协议。
