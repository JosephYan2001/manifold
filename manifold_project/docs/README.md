## 3. 文档边界和更新规则

1. 理论假设与推导以理论主稿为准；empirical 工程变体不自动继承 Hoeffding 保证。
2. 环境具体设置、评价时机、种子和命令以该环境最新详细设计/运行说明及实际配置为准。跨环境总览只汇总，不再维护第二套数值。
3. 结果事实以对应 suite 的 manifest、状态和原始记录为准；旧分析报告保留当时口径，新增维护说明，不改写历史数值。
4. 有协议差异时先明确修订再执行。例如导航详细设计的 100 回合节点评价替代早期通用草案中的 50 回合建议；不是同时执行两套要求。
5. 旧方案归档并保留来源说明。归档文件中的种子、文件布局和待办属于历史，不用于当前运行。

日常推进先读实验总览，再进入对应环境文档；无需顺序阅读所有研究稿。
