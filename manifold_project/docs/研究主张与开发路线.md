# 研究主张与开发路线

理论以[CTDE 方向学习主稿](策略流形研究设计.CTDE本地策略改进版.md)为准，研究安排见[总体实验方案](总体实验方案.md)。本文件维护当前证据和下一阶段顺序，不重复运行命令。

## 核心问题

在规定的本地信息和一个源规模下，用团队经验学习动作概率的改进方向，再由共享 Actor 实现，检验规模变化后何时继续有效。

AN 与 SA 估计同一总体方向目标，研究有限样本波动、成本和优化差异；方向方法与 DA/PPO 研究先学方向再实现的实际价值。样本充分后 AN 与 SA 接近是合理结果，不要求 AN 在任何条件下都胜出。

跨规模执行能力、源经验的约束能力和最终任务表现是不同问题。固定网络参数尺寸只解决输入兼容；观测聚合是否充分、目标行为是否受源经验约束，仍需独立证据。

## 下一阶段顺序

1. [六组训练分析](../experiments/results/evidence/navigation/navigation_batch_lr_2m_s40_20261019_v1/analysis_20261022/六组训练与旧基线对比.md)已完成，实际总交互 12,580,529 步；不自动延长六组或继续扩大矩阵。
2. 不再默认追加两组 500k，也不重复教师收益复核。下一项仅考虑固定数据的 Critic 数值机制验证：单独检验价值目标尺度处理能否恢复独立数据上的状态区分，尚未实施；具体证据与限制见最新结果报告第 6 节。
3. 只有机制验证有效才考虑一个受控短训练；若价值指标改善而教师/执行收益仍无增量，就不能再把 Critic 或 Actor 拟合当充分解释，应评估方向网络路线的必要性。不同时改奖励、网络、方向预算和 η，不自动扩预算。
4. 跨规模、仓库及正式算法比较在源学习证据更充分后另立方案，目标评价不用于挑选源参数。

[已完成六组实验的原始方案](../experiments/results/notes/导航采样量与学习率六组实验方案_20261019.md)。更早行动建议见[历史执行建议](../experiments/results/archive/notes/历史执行建议_20261019.md)，不与上面的后续建议并列执行。

## 维护边界

理论修改进入主稿，环境职责和研究问题进入总体方案，代码层级进入项目结构说明，具体导航设置和命令进入导航手册，实验判断进入对应结果报告。历史归档和运行快照保持原始含义。

导航的自举标签与跨策略连续采样是应用近似，不能直接套用独立完整回合或精确优势条件下的保证。奖励提高、任务成功与零样本迁移优势分别检验；没有目标覆盖保证时如实标为经验外推。
