# 研究主张与开发路线

理论以[CTDE 方向学习主稿](策略流形研究设计.CTDE本地策略改进版.md)为准，研究安排见[总体实验方案](总体实验方案.md)。本文件维护当前证据和下一阶段顺序，不重复运行命令。

## 核心问题

在规定的本地信息和一个源规模下，用团队经验学习动作概率的改进方向，再由共享 Actor 实现，检验规模变化后何时继续有效。

AN 与 SA 估计同一总体方向目标，研究有限样本波动、成本和优化差异；方向方法与 DA/PPO 研究先学方向再实现的实际价值。样本充分后 AN 与 SA 接近是合理结果，不要求 AN 在任何条件下都胜出。

跨规模执行能力、源经验的约束能力和最终任务表现是不同问题。固定网络参数尺寸只解决输入兼容；观测聚合是否充分、目标行为是否受源经验约束，仍需独立证据。

## 下一阶段顺序

1. 按[导航实验手册](../experiments/cooperative_navigation/README.md)运行 AN 无检查和 MAPPO-E 的同预算单种子源训练，另以 AN 双检查和 DA 完整版观察检查开销。
2. 核对源成功率、距离、Critic 解释方差、实际 KL、接受更新和成本。必要的参数诊断一次改变一个因素；延长预算也只依据源趋势。
3. 源任务出现可靠学习后，冻结共同设置、增加独立训练种子，再运行跨规模评价。目标结果不得用于挑选源 checkpoint 或超参数。
4. 根据源诊断安排输入、关系结构、检查或拟合实验；固定方向诊断须在源训练前启用。随后以仓库检验跨任务表现。

200 万步是初步观察预算，不是收敛保证。更长预算与正式评价精度在源诊断后确定；不要求先跑满所有应用，也不因某方法暂未胜出而改变研究主张。

## 维护边界

理论修改进入主稿，环境职责和研究问题进入总体方案，代码层级进入项目结构说明，具体导航设置和命令进入导航手册，实验判断进入对应结果报告。历史归档和运行快照保持原始含义。

导航的自举标签与跨策略连续采样是应用近似，不能直接套用独立完整回合或精确优势条件下的保证。奖励提高、任务成功与零样本迁移优势分别检验；没有目标覆盖保证时如实标为经验外推。
