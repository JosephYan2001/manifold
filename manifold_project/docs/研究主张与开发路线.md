# 研究主张与开发路线

更新：2026-09-24。理论、网络候选和研究验收以[CTDE 方向学习主稿](策略流形研究设计.CTDE本地策略改进版.md)为准；具体环境、实验清单、对照和预算统一在[总体实验方案](总体实验方案.md)。本文件只维护进度和顺序。

## 1. 当前主张

在规定的本地信息和一个源规模下，用团队经验学习动作概率调整，再由共享 Actor 实现，分析真实人数变化后何时继续有效。

保留三个贡献候选：解析 Fisher 与采样平方经验估计的差异；方向到共享 Actor 的实现与误差；条件跨规模运输和一步成对交互偏移。输入结构为这些问题服务。通用充分表示、一般源外识别和最终性能保证不再作为必须先完成的联合课题。

## 3. 近期顺序

1. 使用已经接通的入口运行 P-E、P-A、P-T pilot，确认有限样本估计、实际拟合和目标偏移的结果能分开解释，再运行正式种子。
2. 运行 P-I/P-L/P-B 与 T-V/T-L，分别保留精确诊断和经验训练。P-I 当前实现精确映射分解，神经学习部分不冒充已完成。
3. 导航先做单种子源预实验，再按源趋势冻结共同预算和参数，开展 N-C/N-T/N-F，随后做输入/结构对照及有需要的单检查消融。
4. 运行仓库 W-C/W-T 检查跨任务表现。无覆盖保证的目标明确记为经验外推，不借网络兼容性冒充定理适用；推进不以 AN 必须胜出为条件。

**下一项具体交付：P-E/P-A/P-T 的 pilot 结果及相应判断。** 启动命令见[实验模块](../experiments/README.md)，研究任务标准见主稿附录 C.3；工程检查产物已清理，不混入正式 results。

## 4. 场景和边界

成对模型承担精确机制检验。归一化导致方向随人数不变时如实报告该恒等式，并增加总交互权重随人数变化的对照，不能将不变性当作方法专属优势。

导航采用首次同时覆盖全部目标结束，当前读取原生允许的完整目标/同伴相对位置列表，并已按锁定版本核对字段；这不是有限视距任务。仓库沿用原生局部视野，固定地图和请求量测试人数变化。任务期限与采样切断分开处理；奖励提高、任务成功和最终零样本优势分别检验。具体设置见总体方案第 2 节。
