# 实验共同执行协议

更新：2026-09-17。本文件保留旧链接入口，现只维护跨环境共同规则。各环境做什么见[实验总览](实验执行矩阵.md)，阅读顺序与进度见[文档导航](README.md)。旧逐项数值协议已[归档](archive/实验执行矩阵_详细协议_20260916.md)。

## 1. 方法和消融定义

| 方法 | 定义 | 适用环境 |
|---|---|---|
| ours / Ours-E | 解析 Fisher 方向、指数目标、前向 KL 拟合、两项 empirical 检查 | 三环境 |
| sampled / Sampled-E | 只替换方向损失二次项，保留其他设置 | 三环境；同时承担解析项消融 |
| PG | 每批新数据一次直接策略梯度 Adam 更新，优化器跨轮保留 | 成对协作 |
| MAPPO / IPPO | 共享本地 Actor 的 PPO；分别采用集中/本地 critic，相同团队奖励 | 导航已实现并完成 smoke；仓库尚待实现 |
| no_direction_check / NoDir | 不采方向检查数据，直接构造候选 | 三环境 |
| no_return_check / NoRet | 不采回报检查数据，接受首个数值有效候选，取消回报驱动的步幅回退 | 三环境 |
| fit_quarter / FitQuarter | Actor 拟合 epochs/步数减为 ceil(标准/4)，至少 1；其余相同 | 三环境 |

Ours-E 没有 Hoeffding 有限样本保证；Ours-H 若实现应独立标明。固定候选上的 P-H 诊断不等于已完成 Ours-H 全流程训练。MAPPO/IPPO 的比较也不能直接解释为 ours 的 critic 消融。

主比较与消融共用参考运行：成对 6 条件，导航/仓库各 7 条件。解析项消融沿用共同超参数；策略分化后轨迹不再相同，不称为共享训练数据。消融不单独调参，不与所有目标规模做笛卡尔积。

## 3. 预算与评价分账

- 源优化预算包含训练、critic 专用采样、方向检查、旧/新策略回报检查及候选回退成本。同一团队联合步不乘机器人数；epoch 不增加交互数，但计入计算量。
- 相同预算不要求相同外层轮数。不超支，不足以启动下一轮时报告余量；删除的检查不继续偷偷采样。
- 仅用于报告的独立评价不能参与接受、优化或正式选模，成本单列，同时报告总运行资源。源调参使用单独开发种子，目标评价不用于调参。
- 曲线按共同预算节点读取不超过节点的已提交模型，不插值未来策略。成对可精确积分；导航使用预定节点的评价近似，不混称为同一种无噪声指标。
- 主结果与冻结迁移使用 final；best 只作开发诊断。部署时冻结 Actor 与预处理，critic、方向网络和接受检查不参与动作选择。

## 4. 统计与公平性

完整训练以独立训练种子为统计单位：先对每个模型的评价回合平均，再跨种子报告均值、标准差、95% 区间与逐种子值。配对差异按共同训练种子重采样，不把回合或时间步伪装成更多训练重复。机制估计以独立数据集为单位，analytic/sampled 配对时校验数据一致性。

成对新 P-H 使用 Wilson 95% 二项比例区间；0/200 不表示真实错误率为零。旧 pilot 表保留当时 bootstrap 口径，不能因新代码变化宣称旧数据已经重算。P-M2/P-M4 的确定性核验不人为重复产生置信区间。

区间默认为逐比较区间。若做多项显著性检验，事先固定比较集合并处理多重比较。未发现差异不等于证明等价，零观测退化不等于保证安全。应用没有精确方向或回报真值，检查样本差不能当作真实更新增益。

各基线获得预先规定的开发机会，记录实际使用的标签、网络、概率分布、PPO 设置和学习率；没有充分调参的基线要如实说明。当前成对 PG 固定 0.001，不能称为经过穷尽调参的最强基线。

失败、NaN、停滞、未达阈值均保留。中断记录已采集但未提交成本，不反复补跑到成功。阈值成本同时报告达到比例与未达到数量，不能只比较成功种子的均值。

## 5. 冻结迁移与数量

| 环境 | 正式训练规划 | 冻结评价 |
|---|---:|---|
| 成对 | 60 次 | 机制方向运输单列，不把人数控制结果当成一般泛化 |
| 导航 | 70 次 | 4 方法×10 模型×N=3/4/6/8×200 回合；N=4 复用 final 源评价，仅额外 24000 回合 |
| 仓库 | 70 次 | 4 方法×10 模型×N=2/4/6/8×200 回合；源规模是否复用由仓库详细协议冻结 |

三环境总计 200 次为规划数量，不是已完成数量；开发、可选诊断和标签对齐实验另计。导航的覆盖判据为终点距离严格小于 0.1，碰撞为唯一无序对数及每机器人碰撞数；源每个非 final 正式评价节点 100 回合，final/每目标规模 200 回合。不要再引用旧通用草案的 50 回合节点评价或“除以总对数”作为导航主碰撞指标。

## 6. 交付标准

冻结配置、代码和依赖版本，记录每个预定条件/种子的完成或失败状态，保留可核对的日志与成本表；主图表回答事先规定的问题。成对子运行采用 4 个 JSON＋1 个 events.jsonl，导航已实现 2 个 JSON＋1 个 events.jsonl＋best/final 两个 PT，具体格式见各环境运行说明。

“实现了入口”“完成了 pilot”“冻结了参数”“完成正式实验”“结果支持假设”是不同状态。没有优于基线也可以完成实验；没有执行的数据不得写成论文结果。
