## 1. 研究目标和结论层次

研究目标是：在严格单源 CTDE 下，以团队经验估计本地动作概率的改进方向，将其实现到共享 Actor，并检验规模和交互机制变化后方向与最终策略的表现。最终冻结 Actor 的零样本性能是主要研究目标之一；相对 MAPPO/IPPO 的优势是待检验假设。

| 层次 | 问题 | 应提供的证据 | 不能替代它的量 | 对应实验组 |
|---|---|---|---|---|
| Q1 方向估计 | 解析 Fisher 二次项在什么条件下降低方向估计误差？ | 精确误差；同一冻结策略、共同数据和共同独立评价下的方向比较 | 各自训练 loss；不同策略下的分数直接比较 | P1/P2；N1/W1 |
| Q2 参数实现 | 理想方向的收益有多少被实际 Actor 实现？ | 旧策略、直接指数目标、拟合 Actor 的回报差与拟合误差 | 训练 KL 小；方向检查通过 | P3；N2/W2 |
| Q3 源训练 | 完整方法的收益是否抵偿估计、拟合和检查成本？ | 等总源交互预算的独立回报、任务指标和耗时 | 相同训练轮数；只统计梯度采样 | P6；N3/N4、W3/W4 |
| Q4 方向运输 | 输入覆盖和交互变化怎样影响同一方向？ | 可枚举环境中的覆盖系数、方向偏移、目标误差、界的松紧与反例 | 固定输入输出维度 | P5；N6 仅采样诊断 |
| Q5 冻结部署 | 最终 Actor 在未见配置中是否优于基线？ | 同一目标配置下的冻结策略比较，并列源表现 | Q4 单轮方向结论；不同规模原始回报直接相减 | P6 冻结评价；N5/W5 |

表中实验编号对应第 5–7 节的 R1 设计组，不是当前 CLI 参数；P4 负责检查规则，P7 负责有限多步方向机制。

理论主稿允许变长实体列表和可训练内部特征。“固定信息协议”指信息权限、字段含义和构造规则固定。正方向分数、实际有限步改善、全训练收敛、最终目标性能是不同结论。

输入覆盖及有界密度比是当前运输定理的充分条件，不是所有学习算法成立的必要条件。本方案把定理核验放在可证明满足前提的机制环境；应用任务只使用已适用的核心方向理论，不宣称原生导航/仓库跨规模自动满足运输界。

当前优先工作是成对机制精确核验、导航结构可识别性与有限多步诊断。若要求导航或仓库承担现有运输定理的直接验证，必须先满足相应前提或完成新理论；将它们列为经验推广实验需要明确缩限主张，不能默认为已经满足用户要求的理论对应。

### 2.1 理论与实验之间尚缺的保证

| 环节 | 理论要求或已知关系 | 当前缺口/状态 | 用什么补足；什么不能替代 |
|---|---|---|---|
| 任务与信息 | 固定执行信息、非空合法动作集、合法动作内点、有限期及有效回报界 | 应用协议与源码尚需逐项验收；导航零步成功需明确扩展且 Z>0 | 接口/数学核验；网络维度相同不等于信息合法 |
| 经验标签到真实方向 | 真优势定义总体目标；完整 MC 减预冻结动作前基线可构造对应估计 | GAE/片段 bootstrap 的偏差未获统一控制；相关时间步不能当独立样本 | 先用精确模型和完整回合核验；Critic loss 小不等于标签无偏 |
| AN 相对 SA | 总体二次项一致；经验差异与方差收益有条件 | 尚无对所有函数类、优化器和任务的 AN 误差更小保证 | 同快照、同数据、同优化预算与独立误差评价；各自训练 loss 不足以归因 |
| 方向到 Actor | 正总体方向只给局部小步信息；实际参数实现需要表达与误差条件 | 有限数据平均 KL 不给全访问域的统一误差；非凸优化未保证实现目标 | 旧策略/指数目标/拟合 Actor 三策略诊断；需要对应误差界才能作保证 |
| 接受检查 | 置信结论需有效界、候选固定、独立回合和跨候选/跨轮错误预算 | 经验均值检查没有有限样本安全保证；应用奖励界需推导 | 检查误接/误拒绝及成本；经验通过率不能称可靠性证书 |
| 一轮到全训练 | 主稿没有普遍全局收敛定理；一阶停止点可能有二阶协作收益 | 延长预算不能保证收敛、最优或优势持续 | 源曲线和平台规则只给经验判断；保留失败，不以训练轮数代替证明 |
| 跨规模输入覆盖 | 同一输入/动作语义、目标占用绝对连续及有限密度比 | 导航固定目标数+完整有效位有确定反例；仓库有待核验的新增局部人数模式 | 证明允许环境族的覆盖或发展替代理论；padding、mask、采样重叠和源动作正概率均不够 |
| 跨规模方向偏移 | 需控制同一比较对象的长期条件方向变化 | 一步成对界仅适用于该机制；导航终止/未来协作、仓库补货/拥堵未获结构性界 | 明确共同结构、源可识别性、组合误差及长期残差；有限大上界不等于有用保证 |
| 单轮到最终零样本 | 当前运输结果固定同一旧策略与方向 | 尚缺多轮占用变化、拟合误差累积与最终性能的桥梁；无相对 MAPPO/IPPO 的普遍优势定理 | 额外理论与严格冻结比较分别提供证据；单轮正方向或源训练胜出不能替代 |

上述“尚缺”区分三类：已知不满足的假设、尚待证明的假设、只计划用实验检验的性能假设。不得统称为实现 bug，也不把没有证明写成不可能。每个环境的验收记录需分别列明适用命题、具体前提、证据和仍未解决的条件。

## 3. 算法定义

### 3.1 公共数学对象

在一轮中冻结旧策略 \(\mu\)，Actor 和方向网络使用同一本地输入 \(X_i\)。给定完整动作前历史，各机器人独立采样。定义：

\[
S(X,A)=e_A-\mu(\cdot\mid X),\qquad
F(X)=\operatorname{Diag}(\mu)-\mu\mu^\top.
\]

\[
\mathcal B_\mu(q)=
\mathbb E_\mu[2A^-S^\top q-q^\top Fq],\qquad
\mathcal E_{\mathrm{loc}}-\mathcal B_\mu(q)
=\|q-v^{\mathrm{loc}}\|_{F,\mu}^2.
\]

期望采用主稿规定的旧策略折扣访问分布和机器人平均。理想分数使用真实团队优势；实现用估计标签，标签偏差不得从上述恒等式中省略。

AN 的经验方向损失为 \(q^\top Fq-2\widehat A S^\top q\)；SA 仅把二次项换为 \((S^\top q)^2\)。两者都采用回合内 \(\gamma^t\) 权重、相同机器人平均和相同归一化。训练分数是自归一化估计，不声称有限样本严格无偏。

方向分量零和且满足 \(\|q\|_\infty\le q_{\max}\)。方向网络与 Actor、Critic 均不共享可变参数。Actor 可通过混合均匀分布实现概率下界；下文机制模型采用 \(\beta=0.02\)，应用中的具体下界与结构待协议冻结，不把示例数值当作已定训练配置。

### 3.2 一轮完整更新

1. 冻结完整旧 Actor、输入适配状态及标签 Critic。
2. 用旧 Actor 采集完整源回合，保存原始输入、动作、旧概率、团队奖励、时间和回合标识。
3. 用完整折扣回报减冻结动作前基线构造标签；训练方向网络。参考版本每轮重新初始化方向网络，所有配对方法共用初始化种子。
4. 方向训练结束后固定 \(q\)，另采独立完整源回合进行方向检查。
5. 检查通过后构造 \(\widetilde\mu_\eta(a|X)\propto\mu(a|X)\exp(\eta q_a(X))\)。
6. 每个候选均从旧 Actor 的完整副本开始，用前向 KL 拟合固定目标。拟合输入只来自本轮旧策略的训练回合，采用同一折扣访问权重和机器人平均；不能另换候选策略的访问分布。候选步幅依次为 \(\eta,\eta/2,\eta/4\)，最多三次。
7. 固定候选，另采独立完整源回合比较新旧策略的期望任务回报；通过才提交，否则回退或保留旧策略。
8. 本轮采样结束后训练 Critic，供下一轮冻结使用。Critic 训练不得改变 Actor 或已经使用的标签。

本轮旧概率、标签和指数目标不能随着 Critic、方向网络或 Actor 的优化悄悄重算。所有梯度阶段必须排除填充数据。

训练批、方向检查以及每个回报候选的新旧策略回合数，均须在源开发前按费用与统计精度登记，不沿用先前未定的固定配额。批末不得把片段自举回报称为完整 MC；指定回合数本身不提供检查可靠性的承诺。

回合长度预先有上界。启动采样前预留足够的最坏回合费用；预算不足则结束并记录余量，不超支，不把最后的半回合混入完整 MC。实际账目以真实团队步为准。

### 3.3 标签与 Critic

机制主标签：完整 \(G_t=\sum_{\ell=t}^{T-1}\gamma^{\ell-t}R_\ell\) 减评价数据生成前已经冻结的动作前基线。精确优势只在可枚举机制组作为 oracle 诊断，不能只供 AN 正式训练使用。

AN/SA 完整训练的参考标签也采用完整 MC。GAE（参考 \(\lambda=0.95\)）和片段 bootstrap 作为明确命名的工程变体，AN/SA 同时切换，并记录所依赖 Critic 的输入、训练数据和偏差来源。

机制比较不对每个方法分别用当前样本标准差重缩放优势。若要标准化，必须事先固定共同规则，并把尺度对方向和步幅的影响写入算法定义。作者 PPO 保留其声明的优势标准化，作为整算法差异披露。

Critic 输入全部为动作前信息。集中 Critic 可以读取团队执行历史和获准物理状态；IPPO Critic 只能读取本地 Actor 输入。完整 MC 的基线误差与 GAE 的自举误差分别解释。

### 3.4 检查版本与消融

| 标识 | 定义 | 实验职责 |
|---|---|---|
| AN-E | AN、指数目标、Actor 拟合、两项经验检查 | 主稿完整方法的主应用版本 |
| SA-E | 仅把 AN 训练二次项替换为采样平方 | 核心估计方法对照 |
| NoDir | AN-E 删除方向检查及其采样 | 单模块消融 |
| NoRet | AN-E 删除回报检查及回报驱动回退，采用首候选 | 单模块消融 |
| NoChecks | 删除两项检查 | 联合消融，不能替代两个单模块组 |
| Fit-1/4 | 仅减少 Actor 拟合预算 | 优先用于固定快照敏感性 |
| AN-H | 独立的有置信控制版本 | 只在已建立有效界的机制组检验 |
| Oracle-check | 用精确分数/回报作检查 | 可枚举诊断，不参加现实样本效率主排名 |

AN-E/SA-E 都采用同一个独立解析方向评价分数，避免同时改变训练和检查两项因素。经验方向均值大于零才通过；回报差均值大于零才接受。两者均不宣称有限样本安全保证。

方向独立检查使用回合统计
\[
Y_j=\frac1n\sum_{t<T_j}\gamma^t\sum_i
[2\widehat A_{j,t}S_{j,t,i}^{\top}q(X_{j,t,i})
-q(X_{j,t,i})^\top F(X_{j,t,i})q(X_{j,t,i})].
\]
其期望是正归一化常数乘总体方向分数，正号一致。按完整回合计算区间，不把机器人和时间步当独立重复。

AN-H 必须先证明 \(Y_j\) 和回报差的有效界，再分配跨轮、跨候选总错误概率。依据前一批检查结果产生下一候选时，使用新的独立检查回合；不得反复复用同一批数据并宣称独立检验。

指数目标可能低于 Actor 的概率下界。记录目标最小概率、不可达分量和拟合残差；缩步按预定候选表执行，不静默截断目标或修改 KL 定义。

### 3.5 对算法修改的管理

允许修改原算法，但每项修改必须给出：要解决的数学误差、改变的定义、仍适用的命题、失去的保证、独立对照和采样成本。只用源开发数据决定是否进入下一协议版本。

本方案预留三个有明确动机的修改候选：

- 方向热启动：仅复用上一轮参数作为初始化，仍优化本轮冻结策略下的新目标；不把旧方向直接当当前方向。
- 标签变体：AN/SA 成对切换 MC 与 GAE，评价标签偏差和方向质量的权衡。
- 检查变体：改变检查样本量或采用已证明的置信规则，分别考察统计误判与交互成本。

方向 EMA、共享 Actor/Critic 编码器、辅助奖励、内在探索奖励、额外任务分配器不是默认组成。若提出，必须作为新算法或新任务协议先定义，再比较；不能在正式训练途中加入。

## 4. 基线与公平比较

主应用基线为锁定提交的作者 MAPPO 和 IPPO；保留作者的 PPO 更新、价值归一化等已声明机制。二者在同一任务中分别使用集中和本地 Critic。固定版本与项目适配分别记录，不能把作者网络与更新均有改动的版本写成原样复现。

共同条件：任务、信息权限、原生动作语义、Actor 输入格式与历史、训练/评价奖励、终止规则、源重置分布、源调参预算、正式交互预算、评价场景和随机动作执行规则。

Actor 采用相同输入和相近容量。作者实现中的归一化、初始化、概率头等差异逐项披露。公平不要求 \(\eta\) 与 PPO clip 数值相等，也不要求不同用途的损失权重数值相等。

应用网络的宽度、深度和激活在协议验收后登记。方向网络与 Actor 的参数独立；机制比较控制相应函数容量，全部集中方法读取相同集中信息。旧配置中的网络数值不自动成为新方案设置。

理论归因分两层：
- AN 与 SA 的共同数据实验仅改变二次项，是主要机制对照。
- AN-E 与作者 PPO 的完整训练回答整算法表现。若要归因于更新目标本身，再增加 Actor、标签、初始化和标准化对齐的 PPO 控制，明确称为对齐控制，不能替换作者主基线。

所有方法都使用预定源调参机会。SA 和单模块消融继承 AN-E 参数，不各自寻找最佳设置；这一约定服务于消融，不声称 SA 已被单独最优调参。另行独立调优 SA 时单列表格。

## 5. 成对协作：可证明、可精确计算的机制族

### 5.1 一步冲突任务

该方案采用个体偏好与协作偏好存在冲突的任务，独立于旧任务数据：

\[
X_i\in\{0,1\},\quad a_i\in\{-1,+1\},\quad
R=\sum_i b_{X_i}a_i+
\frac{\rho}{n-1}\sum_{i<j}a_i a_j,\quad b=(-0.2,0.3).
\]

源配置为 \(n=4,\ p(X=0)=0.5,\rho=0.2\)。每回合一步；类型 iid 重置；Actor 只读自身类型。机器人编号不进入 Actor，集中信息只用于基线。正式训练无 oracle 优势。

公共机制族预先限定 \(n\in\{2,4,6,8\},p\in[0.1,0.9],\rho\in[0,2]\)。该范围内 \(|R|\le n(0.3+\rho/2)\)，类型全支持，所以一步输入覆盖可证明，\(\kappa=\max_x p_t(x)/p_s(x)\) 可精确计算。

采用 \(\beta=0.02\)，动作均值 \(m_x\in[-0.98,0.98]\)，有
\[
J/n=\sum_xp_xb_xm_x+\frac{\rho}{2}\left(\sum_xp_xm_x\right)^2.
\]
在 \(p=0.5\) 下，比较四个边界顶点可得：源 \(\rho=0.2\) 的约束最优上确界由 \(m=(-0.98,0.98)\) 取得；目标 \(\rho=0.6\) 则偏好 \(m=(0.98,0.98)\)。这是一项训练前的数学设计，保证目标族并非处处共享同一最优决策；不要求冻结策略在互相冲突的目标上都最优。

预定目标组：

| 组 | 设置 | 要验证的内容 |
|---|---|---|
| 人数结构控制 | n=2/6/8，其余同源 | 本构造中方向和 J/n 的人数不变性；适用于所有策略 |
| 小幅机制变化 | 固定 n=4；分别 p=0.4/0.6 或 rho=0.1/0.3 | 精确偏移、上界松紧及何时保留正方向 |
| 决策边界 | 固定 n=4,p=0.5；rho=0.6 | 源最优策略与目标最优策略可不同 |
| 强偏移诊断 | n=4,p=0.9,rho=2 | 覆盖成立但方向可翻转；不预设零样本成功 |
| 支持失效诊断 | 单独用缺失某类型的参考源，目标引入该类型 | 明确展示运输界适用条件失效，不并入主源训练 |

### 5.2 有真正时间影响的多步扩展

在同一机制项目中增加有限时域 \(H=3\) 的独立单源任务。每个机器人有固定类型 \(x_i\)、可变模式 \(s_{i,t}\in\{0,1\}\) 和动作 \(a_i\in\{-1,+1\}\)。本地输入为 \((x_i,s_{i,t},t)\)，不包含人数或其他机器人状态。

\[
R_t=\sum_i b_{x_i}a_i+
\frac{\rho}{n-1}\sum_{i<j}a_i a_j
-c\sum_i\mathbf1\{a_i\ne2s_{i,t}-1\}.
\]

\[
P(s_{i,t+1}=1\mid s_t,\boldsymbol a_t)=
\epsilon+(1-2\epsilon)\left[
(1-\lambda)\mathbf1\{a_i=+1\}
+\frac{\lambda}{n-1}\sum_{j\ne i}\mathbf1\{a_j=+1\}
\right].
\]

给定状态和联合动作，下一模式条件独立。源取 \(n=3,p=0.5,\rho=0.2,c=0.2,\lambda=0.25,\epsilon=0.1,\gamma=0.95\)，初始模式 iid Bernoulli(0.5)。目标只在预定轴上变化：n=2/4；或固定 n=3，lambda=0/0.5/0.75；或 rho=0.1/0.6。每轴分别报告。

动作改变后续模式，模式改变后续成本和策略，因而不是独立一步博弈的重复。实现验收必须用一个两步反事实确认 \(Q_t-R_t\) 随当前动作变化。

该有限模型可按类型、状态、动作、下一状态枚举，反向求 Q/V，正向求折扣占用。n<=4、H=3 时朴素每阶段约 \(2^{4n}\) 项，适合精确计算。

有限共同本地输入空间、严格正类型/初始模式概率和 epsilon>0 保证源中每个 \((x,s,t)\) 都有正概率，因此覆盖和有限 kappa 可以证明并精确计算。方向偏移 delta 可精确算出；小幅参数变化是否产生有用的小偏移界仍需推导，不能套用一步成对公式。奖励界为 \(n(0.3+\rho/2+c)\)。

## 6. 合作导航：任务与观测的一体化方案

### 6.1 任务定义

采用锁定版本 MPE2 Simple Spread 的离散原生动力学。源为 4 机器人、4 目标，固定生成区域、碰撞体积和力学参数，关闭课程及动态缩放。

目标为首次同时覆盖全部目标即完成；覆盖定义是每个目标距至少一台机器人严格小于 0.1，不要求一对一匹配。首次成功或第 500 步任务截止都是真终止，终点 bootstrap 为零；初始成功为零步成功，最后一步成功优先于失败。

零步成功保留在任务评价和回合账目中，不产生动作或梯度记录；没有有效决策数据的批次不能用于更新。理论中零步轨迹的 score 贡献为零，允许 T=0 时须记录这一扩展并要求参考分布的期望折扣决策质量 Z>0，不通过反复重置偷偷改变源分布。

团队奖励沿用明确的原生混合均值：
\[
R_t=-0.5\sum_{k=1}^{M}\min_i\|p_i-\ell_k\|-C_t/N,
\]
其中 C 为唯一无序碰撞对数。不在本版本额外增加成功奖金、探索奖励或目标分配奖励。理论 J 是完整任务折扣回报的期望；成功率和完成时间是另列任务指标。

正式实现按锁定源码核对奖励系数。500 步是任务定义，不是原生环境不可更改的限制；本方案冻结后不得在正式比较途中改变。

### 6.2 全目标可见、固定容量的候选观测

完整目标信息是任务要求；以下固定容量表示只作候选，尚未通过第 6.2.1–6.2.2 节的理论定位审查，也未作为新代码协议实现。令容量为 C，必须在源训练前确定；8、16、32 都不是理论上限，也不是已经批准的最终设置。

- 每个目标槽包含相对位置 dx、dy 和有效位，共 3 维。M<=C 时全部目标各出现一次；空槽坐标和有效位为零。
- 超过容量明确拒绝，禁止静默丢弃、按距离截断或部署时临时扩充网络。
- 每回合按独立于策略和奖励的随机规则，把真实目标注入 C 个槽；同回合映射不变且各机器人共享。源训练让每个槽有机会有效，但不会因此覆盖其他目标数量的联合输入。
- 使用规范坐标排序再抽取映射，记录独立随机数；各算法共用评价映射。
- 自身位置/速度可用；其他机器人只提供最近 2 台的相对位置和有效位。目标地图不额外包含占用标签、全局机器人位置或集中任务分配。

沿用 8 帧历史、每帧过去动作 one-hot 5 维与历史有效位、一个 t/500 时钟时，候选输入维度为
\[
d(C)=8(4+2\times3+3C+5+1)+1=129+24C.
\]

若源仍为 4 人，集中 Critic 的拼接维度为 4d(C)。这是候选结构的形状计算，不代表容量、结构或现有代码已经确定。集中 Critic 不迁移，目标评价只调用冻结 Actor。当前动作不能进入当前输入；起始过去动作置零。集合编码、历史结构改动或共享特征需另行审查，不作为默认补丁。

目标有效位属于观测掩码。原生五个物理动作不会随目标数增加；不默认改成“选择目标”动作或引入底层控制器。合法动作屏蔽可使用主稿已有的 M(x) 框架，但掩码必须由执行信息决定，合法概率保持正值，采样/估计/拟合采用同一规则。它不能补足输入覆盖，也不能暗中加入中央分配。

此候选保证的是容量以内完整传递目标坐标与固定接口，不保证 MLP 使用所有信息、排列不变或迁移成功。

特别地，有效位可恢复目标数，所以该完整地图输入在不同固定目标数间仍有支持差异，不能引用主稿现有密度比运输定理来保证导航扩规模。结构兼容、核心方向理论适用、具体运输界适用必须分别记录。若论文要求导航所有迁移目标也有该界保证，需要另行建立结构性推广理论；本方案不伪称已经完成。

固定容量表示仅支持预先声明的有界规模。最终容量应在理论定位和目标规模范围确定后冻结；扩大容量本身不是理论改进。

### 6.2.1 正式冻结前的理论适用性核验

槽位容量与掩码只解决接口和信息传递问题。8、16、32 等容量均属于表示设计选择，不能据此宣布跨规模理论问题已解决。若要求导航跨规模实验直接检验当前运输定理，必须先通过本节核验，再冻结观测、环境族和正式训练配置。

当前“固定源 4 目标、目标环境为其他目标数、完整有效位随输入传入”的方案已经有确定的覆盖反例。令 c(x) 为当前帧目标有效位之和，E={x:c(x)≠4}。对非零的折扣决策占用分布，源中 nu_source(E)=0，任何固定非 4 目标的目标环境中 nu_target(E)=1。因此 nu_target 不对 nu_source 绝对连续，不存在主稿所要求的有限密度比上界。该结论无需训练结果；扩大槽数、随机排列槽位和屏蔽空槽均不改变 c(x)。它否定的是当前运输定理在此协议上的直接适用性，不是否定算法本身或所有可能的迁移理论。

必须依次核验：

1. **共同语义与覆盖。** 固定输入字段、合法动作、归一化及执行适配；给出分布覆盖与有限密度比的证明，或明确反例。源动作概率均为正不等于源输入覆盖目标输入；有限采样未发现差异也不能证明覆盖。
2. **方向偏移。** 覆盖失败时，源条件方向在源零测输入上的值不能从源分布唯一确定，不能任意延拓后宣称获得可识别的方向偏移界。须先提供有效的共同表示/比较规则或新的结构性假设，再推导多步方向偏移及其非平凡适用范围。一步成对奖励的偏移公式不能直接套用导航。
3. **终止与长期影响。** 保留“首次同时覆盖全部目标即终止、500 步截止”时，必须把成功事件、存活时间、折扣占用及未来团队回报纳入分析。增加远处目标可改变终止时间和动作的长期价值。终止规则本身不必然使所有覆盖条件失败，但不能只分析初始分布或即时奖励就忽略这些变化。
4. **实验诊断与证明分工。** 冻结策略下的方向评分、三策略比较及目标表现能检查实际现象和构造反例；它们不能替代绝对连续性、统一密度比上界或一般方向偏移界的证明。通过单轮方向核验也不等于已证明最终 Actor 优于 MAPPO/IPPO。

研究决策必须明确选择并记录其后果：保留导航任务时，若要维持跨规模理论主张，需补充能够处理上述支持差异的结构性理论；否则调整环境族并重新证明前提。只增减机器人而固定目标集合会改变迁移问题，源训练混合目标数量也会改变当前固定规模单源设定，均不能静默采用。若保留现方案而只把导航列作经验推广检验，则须明确缩限论文主张；这不等于已经满足“导航迁移直接受当前理论支持”的要求。

在上述理论定位未确定前，第 6.2 节的槽位方案和第 6.4 节的迁移组保持候选状态，不据此启动用于确认理论主张的正式长预算比较。可继续独立的数学核验、机制模型及接口检查。

### 6.2.2 当前下一步：一次有明确交付的理论可行性审查

本轮保留研究约束：固定规模单源训练、首次同时覆盖全部目标即完成、执行期固定五个物理动作、容量以内全部目标信息可用、集中信息不流入 Actor。槽容量和网络结构暂不冻结；不以扩大到 32 槽或增加 mask 作为覆盖问题的解决证据。本节只规定下一项审查，尚未完成新命题证明或对应程序实现。

| 顺序 | 具体工作 | 完成交付与判定 |
|---|---|---|
| 1 | 固定源/目标环境、输入、动作、回报、终止和拟证明结论 | 一页问题定义；明确当前目标是有条件的方向运输，最终冻结策略比较另列；保存第 6.2.1 节已经成立的覆盖反例 |
| 2 | 审查共享结构能否从固定规模源数据识别 | 列出候选共享函数与组合规则；寻找“源中完全一致、目标中不同”的函数对；没有额外可识别性论证时不进入架构冻结 |
| 3 | 建立下面的有限多步导航诊断 | 精确 Q/V、折扣占用、本地方向和终止事件；给出候选关系或残差的精确值及反例，不进行大规模训练 |
| 4 | 写出一条候选跨规模命题并完成证明或反驳 | 每个结构、覆盖、可识别性和残差假设有明确含义；界必须在声明的非退化子族中足以支持其结论，不能只把未知目标误差改名为常数 |
| 5 | 决定导航的论文角色，再冻结工程协议 | 能证明有限模型不等于能证明 MPE；须另审查 MPE 动力学和终止是否满足假设。通过后再确定容量、实现和源开发；未通过则保留“导航理论支持尚未建立”的结论，并明确提出环境族或论文主张的修改 |

共享函数的可识别性已有一个直接检查例。若候选方向采用

\[
q_M=b+\sum_{j=1}^{M}f(z_j),
\]

则对任意足够小的非零动作零和常向量 c，令 b'=b-4c、f'=f+c。在源 M=4 的所有输入上 q'_4=q_4，而在目标中 q'_M-q_M=(M-4)c。选取有界常函数即可让两组方向都满足给定有限容量内的幅度约束。因此，即使源方向被无限数据准确确定，未经约束的这类分解仍不能确定其跨规模延拓。这是对该候选分解的反例，不是对所有共享结构的不可能性证明。

规范约束、已知组合系数或其他结构假设可能排除这类歧义，但必须说明为什么真实任务方向满足它们。改成均值聚合也要重新核对真实方向、奖励尺度和长期交互，不能仅凭形式消除一个反例就宣布迁移成立。本节不预先采用集合编码器，也不改 Actor 的动作含义。

有限模型中先固定线性参数化的单实体/成对特征表，在源、目标各自正占用的本地输入上形成设计矩阵 D_S、D_T，并消除动作公共平移规范。可直接检查 ker(D_S) 是否包含于 ker(D_T)：若存在 D_S w=0 而 D_T w≠0，则没有附加约束时，源证据不能唯一决定目标组合输出。通过这一检查后，还须计算误差从源到目标的放大程度，以及真实方向对同一共享结构的投影残差。矩阵检验只针对声明的有限线性结构，不自动覆盖任意神经网络。

有限诊断模型预定义如下：3×3 格点，源为 2 机器人和目标 {(0,0),(2,2)}，目标环境为 3 机器人并增加目标 (0,2)；机器人初始位置在所有互异有序位置组合上均匀取样，之后允许重合。每步同时选择原地/左/右/下/上，越界动作保持原位；每个目标被至少一台机器人占据即覆盖，首次全部覆盖终止，最长 4 步，gamma=0.95，初始完成为零步轨迹。动作后团队奖励为 -0.5 倍各目标最近机器人 Manhattan 距离之和，再减去同格无序碰撞对数除以机器人数。

该有限模型的本地输入为自身位置、按相对坐标字典序排列的最多两个邻居相对位置及有效位、三个固定目标槽的相对位置及有效位，以及 t/4；目标槽依次对应上述列出的三个坐标，源中第三槽无效。这里不拼接历史，且 n<=3 时邻居字段能容纳全部其他机器人；这两点是精确诊断模型的明确简化，不将其称为完整 MPE 协议。

先固定均匀策略，再固定一个明确的最近目标偏置策略：各动作 logit 为该动作后自身到最近目标的 Manhattan 距离的负值，在 softmax 后混合 0.02 的均匀分布。两者都只使用获准的自身位置和完整目标地图，不依据诊断结果选策略。精确计算中央 Q/V 后，按声明的本地输入条件化得到本地方向；不能自动把中央动作价值称为本地方向。

这只是对多步覆盖、同时终止和规模变化的可枚举模型，动力学不等于 MPE。它能反驳普遍错误的推断，也能检验有限模型内的代数与数值关系；它不能通过一个正结果证明连续导航中的普遍界。若采用实体或关系级共同输入，仍须分别证明该分布上的覆盖、源可识别性、组合误差控制，以及其他机器人和终止事件引入的剩余长期耦合。所有诊断结果与后续正式目标评价隔离；据诊断改变方案后，正式目标评价按新冻结协议重新建立。

本轮停止点是得到可复核的命题证明、明确反例，或准确列出的未解决假设；不把“尚未证明”写成“不可能”。理论尚有缺口时，继续成对机制的独立核验是有效工作，启动导航正式长预算比较不能填补该缺口。若只保留导航的经验比较，必须明确记录论文主张缩限，不能默认为已经满足理论对应要求。

### 6.3 观测验收

候选表示若获采用，在训练前验证：每个真实目标出现一次；无效槽不伪造目标；所有源槽可被激活；输入维度在预定容量内各目标规模相同；零坐标、重合目标、空历史正确；同一回合目标身份不因距离排序跳动而换槽。验收本身不能证明跨规模覆盖。

构造一个远离目标簇的孤立目标，并改变其坐标，确认每个机器人的目标输入发生相应变化。该测试证明目标信息被传入，不证明策略一定前往或完成覆盖。

全局 Critic 字段不能流入 Actor。全目标可见并不意味着其他机器人的动态状态全可见；这是“已知任务地图、局部机器人状态”的 CTDE 协议。

## 7. RWARE：稀疏反馈与资源竞争

仓库承担第二类应用压力测试，不负责替其他环境补足理论。以下为未实现、未冻结的候选协议；需独立记录与第 2.1 节各缺口的对应。没有封装、接口验收和明确的理论定位前，不启动正式训练。

源配置为 4 台机器人、固定地图（shelf_columns=3、shelf_rows=2、column_height=8，生成尺寸在锁定版本中验收）、4 个请求、sensor_range=2、msg_bits=0、GLOBAL 奖励，固定 500 团队步，关闭不活跃终止。

原生动作包含 NOOP、前进、左转、右转、装卸。环境处理无效移动，不增加读取全局信息的安全过滤或任务分配器。

| 编号 | 内容 | 主要判定 |

| R1-W1 | 固定快照、共同完整回合的 AN/SA 方向诊断 | 稀疏标签下的信号量、独立分数及不确定性 |

## 8. 应用环境必须具有的共同机制诊断

### 8.1 固定旧策略和共同数据

应用协议验收后，机制诊断拟采用 AN-E 和 MAPPO 两条源参考轨迹；在各自源预算 0%、50%、100% 取快照，共 6 个参考策略。两种算法的实际初始化、归一化和概率头可能不同，不能把两个 0% 快照自动合并。节点按预算规定，不按表现挑选。参考轨迹使用预先登记的开发种子，费用单列，不作为正式训练重复；当前不安排这些参考轨迹的长训练。

每个冻结 mu 设置预先登记的完整训练回合数档位和独立数据重复；AN/SA 共用原始回合、冻结基线、旧概率、网络初始化和优化次数。另用共同独立完整源回合评价，两种方向均使用同一个解析评价分数。数据量与重复数在应用协议确定后登记；标准误保留共同评价数据与同源快照的相关结构，方向重复不能当作独立 Actor 训练种子。

所有方向、基线、拟合候选及分析规则在访问共同验证池前固定。验证分数不能用来重选方向、步幅或拟合预算；多个已固定对象可以共用评价池并保留统计相关性。若诊断触发下一版本算法修改，新版本使用新的独立验证池，不能反复适配同一池。

精确总体关系为：
\[
\mathcal B_\mu(q_{\mathrm{AN}})-\mathcal B_\mu(q_{\mathrm{SA}})
=\Delta_\mu(q_{\mathrm{SA}})-\Delta_\mu(q_{\mathrm{AN}}).
\]
这允许在共同旧策略下用独立分数差评价相对估计质量；应用环境中仍存在 Monte Carlo 不确定性，不把估计值标成真实 Delta。

### 8.2 三策略诊断

直接执行 \(\widetilde\mu_{\eta,q}\) 只需冻结旧 Actor 与方向网络，无须先拟合新 Actor。对同一快照和方向分别评价：

- \(J(\mu)\)：旧策略；
- \(J(\widetilde\mu_{\eta,q})\)：理想指数目标的实际环境表现；
- \(J(\pi_{\theta^+})\)：拟合 Actor 的实际表现。

步幅和评价回合数随应用协议登记，Actor 拟合预算按参考的 1/4、1、4 倍作受控比较。各拟合预算使用相同旧策略训练输入、折扣权重、固定目标和旧参数起点；各对象使用配对重置场景，策略动作随机流分开。报告两种相对旧策略增益、目标与 Actor 的回报差、训练与独立输入拟合 KL 及其区间。

为控制费用，三策略诊断使用第一个预定数据种子；方向估计重复全部保留。它不用于选择表现最好的方向样本。指数目标只作机制诊断，不与固定容量单 Actor 的部署成本混在主排名中。

拟合后目标回报下降时，结合理想目标自身回报判断属于方向/有限步幅还是参数实现。仅凭 KL 或分数不判定具体原因。

### 10.2 开发与停止的顺序

1. 先完成第 2.1 节相关理论定位、数学与接口验收。
2. 登记小规模源开发候选、开发种子与共同预算，验证数值行为和信号；不能以一次短跑宣称收敛。
3. 在独立源开发种子上比较候选；若按预定规则扩大预算，全部参与候选共同扩展后再选择配置。
4. 只用源回报及预定任务指标选择配置；差异在不确定范围内时，按预定的源 AUC、计算成本顺序处理，不读取目标结果。
5. 冻结正式算法、预算、种子、评价与输出协议，生成对应的可执行配置，再启动完整训练。
6. 全部源模型和分析规则冻结后，执行目标评价。目标结果不反馈本批方法设计。

扩展规则须在开发开始前写明比较窗口、共同改善容差、不确定性处理和最高预算，不能按某一方法的输赢临时制定。到达上限仍无平台证据时报告未稳定；平线但没有学习信号也不能称为良好收敛。

实现错误先修复并记录版本；经核验的算法学习失败属于结果，不删除该组。这些是计算预算与报告规则，不提供全局收敛保证。机制与应用环境分别登记预算，不机械复制旧数值。

### 10.3 评价和计算费用

评价节点按共同源预算定义，读取不超过节点的最近已提交 Actor。评价回合数依据预定精度和源开发方差选择，在正式运行前固定。源参照可以复用同协议 final 评价，不重复采样或重复计账。

迁移费用由方法数、独立训练种子数、非源目标数和每目标回合数相乘得到；团队步上界再乘任务期限，实际提前终止后按实记录。上述数量尚未冻结时，不展示为已经确定的整批费用。

所有方向检查、回报检查及回退采样都计入源训练预算；只用于报告的评价与机制诊断单列，同时报告总计算资源。不得用相同 round 作为公平预算。

## 11. 指标、统计和文件产物

### 11.1 预定指标

- 机制主要指标：Fisher 加权方向误差；理想与实际 Actor 增益；检查误接/误拒绝；运输误差与界。
- 源算法主要指标：独立 J 的 final 与预算归一化 AUC；导航并列成功率与截尾完成步数，仓库并列交付数与零交付率。
- 迁移主要指标：同一目标配置下 AN-E 相对 SA-E、MAPPO、IPPO 的 final J 与任务指标差；并列源表现。不能跨规模直接平均原始 J 后宣称优势。
- 成本指标：训练、方向检查、回报检查分项步数；实际 Actor 提交次数；优化次数；墙钟、峰值显存和评价成本。
- 诊断指标：独立方向分数、拟合 KL、策略更新 KL、熵、最小概率、目标低于概率下界比例、Critic 误差及标签方差。它们均不单独等同任务性能。

### 11.2 统计协议

正式训练、源开发、机制数据、检查数据、源/目标评价使用分离的种子命名空间，具体列表随对应协议登记。旧套件的种子列表不自动沿用为新正式计划。相同任务各算法共用重置场景，动作随机流隔离；相同训练种子不等于训练轨迹相同。

每个训练种子先汇总回合，再跨种子计算均值、标准差和 95% 配对 bootstrap 区间。评价回合和目标规模不是新增训练重复。固定快照机制实验单独统计，不与正式训练种子池化。

主比较集合在正式训练前固定；若使用显著性语言，对同一结论族作 Holm 等多比较校正。效应大小与区间必报；区间跨零不等于等效。所有种子、失败和未达标情况保留。学习曲线 AUC 按左端已提交策略计算，不插值未来 Actor。

### 11.3 文件与图像

每套件一个 manifest.json；每子运行一个 run.json，记录完整有效配置、状态、版本、种子及汇总。常规过程保存 metrics.csv 和 updates.csv；默认不生成逐轮 JSON/JSONL。检查点默认只保留 best.pt 与 final.pt，best 仅作源开发诊断。

预定机制快照统一放入一个 mechanism_snapshots.pt，仅保存固定的 0/50/100% 节点，不恢复每轮 checkpoint。若实现尚不支持此布局，先按验收项修改，不能把计划写成已实现。

每个应用子运行一张 overview.png 汇总 J、任务指标、方向/拟合、接受与成本；每套件另生成方向机制、源学习、冻结迁移各一张汇总图。监控覆盖同一图片文件，不按训练轮次累积图像。目录使用环境、协议、方法、种子和预算的语义名称，时间戳只写元数据。

## 12. 实施顺序和验收清单

| 阶段 | 交付 | 进入下一阶段的条件 |
|---|---|---|
| A 理论与协议固定 | 本方案、算法版本表、环境族与可主张结论 | 按环境分支验收：成对协议通过即可推进 B；导航进入 C 前完成第 6.2.1–6.2.2 节定位审查；不借旧结果预定赢家 |
| B 可枚举机制实现 | 一步冲突源、多步模型、精确 DP、R1-P1～P5/P7 | 奖励、占用、真实方向、误差关系与边界例子通过独立核验 |
| C 导航接口与算法实现 | 按已确定理论定位冻结表示容量及 Actor/Critic 输入，完成完整回合采样和三策略诊断 | 全目标不截断；部署信息不泄露；MC/GAE与终止语义正确；各方法共同协议 |
| D 导航机制与源开发 | R1-N1/N2、预定源候选与长预算验证 | 有可解释的机制证据；算法失败如实保留；参数/预算完成冻结 |
| E 导航正式及迁移 | R1-N3～N6 和单模块组 | 全部源模型冻结后才运行目标评价 |
| F 仓库验收与开发 | 独立审查覆盖/偏移及经验结论边界，锁定依赖、奖励、终止与局部信息、R1-W1/W2 | 明确理论定位，确认交付事件和源信号，完成算法/预算冻结 |
| G 仓库正式与论文整合 | R1-W3～W5、统一机制与应用表格 | 结论逐项对应证据；负结果和边界保留 |

这些阶段不是所有环境共用的一条串行队列。成对机制核验不等待导航理论审查；导航自己的表示与正式比较须先通过对应审查。机制公式和实现验收优先。没有新配置/入口实现前，不提供虚构启动命令。

当前代码至少需要核对或实现：新 pair 冲突源套件、多步 DP；导航全目标槽和新输入模式；完整回合收集替代固定步片段的主 MC；独立三策略评价；新统计/目录协议；RWARE 封装。已有功能可复用，但必须通过 R1 验收，不能把旧任务 checkpoint 直接加载为新输入模型。

本方案不要求各方法必须获得正结果。完成标准是每个问题都有预定、可复核的证据，并且实际结论没有超出其理论和统计适用范围。
