# RWARE 仓库实验

本目录用于后续存放 RWARE 封装、配置、训练、评价和测试。当前只有说明和包入口，尚无环境封装、可运行训练脚本及本地依赖验收记录，也尚未编写独立的完整实验设计。

现有跨环境方案规定：源环境 4 台机器人；固定仓库布局、4 个请求、5×5 局部视野、8 步本地历史；5 个原生动作；500 个团队步；GLOBAL 奖励向量取均值。冻结评价规模为 2、4、6、8，4 为源规模参照；地图、请求队列和视野不随人数改变。这些是待核验的任务约定，不是已运行配置。

## 计划范围

| 实验 | 预定条件与作用 |
|---|---|
| W-C 算法比较 | 完整方法、sampled、MAPPO、IPPO，统一团队奖励与源预算 |
| W-A 消融 | 复用完整方法/sampled；新增去方向检查、去回报检查、1/4 Actor 拟合预算 |
| W-T 冻结迁移 | 复用 W-C 四种方法的 final，评价 2/4/6/8 人，不做目标训练或选模 |

W-C/W-A 去重后为 7 个条件，正式规划每条件 10 个训练种子，共 70 次；每模型/规模评价 200 回合。源规模是否复用 final 评价、正式预算、具体种子、标签、优化参数与评价节点均需在仓库详细协议中冻结，不能直接复制成对或导航配置。主要观察交付数、人均交付、零交付比例、折扣团队回报和计算/检查成本。

首版完整方法按共同协议采用 empirical 工程筛选，不宣称 Hoeffding 保证。若要切换置信版本，另需有效回报界、重复检查预算和独立协议。样本检查差不等于应用环境中的真实回报差。

## 下一步与依据

后续按[三个实验环境构建指南](../../docs/三个实验环境构建指南.md)第 6 章实现，重点核验局部观测、货架交付奖励、动作提交和终点处理。

顺序为：编写仓库详细设计 → 锁定版本与地图 → 随机回合接口验收 → 七条件 smoke → 源 pilot → 冻结正式设置 → 完整训练与冻结迁移。当前不提供尚不存在的训练命令。

研究动机见[研究实验方案](../../docs/策略流形研究设计.实验方案.md)，实验范围见[实验总览](../../docs/实验执行矩阵.md)，计账与统计见[共同执行协议](../../docs/实验执行矩阵_详细协议.md)。完整阅读入口为[研究文档导航](../../docs/README.md)，旧归档不作为执行依据。

各环境分别维护依赖文件。此目录的依赖锁定文件将在实际完成 RWARE 版本核验后生成。
