# 固定教师收益复核：43、44 各 100 对回合

2026-10-18：原 `diagnose` 入口已增加 `--mode teacher-eval`，并通过 [21 项 CPU 工程验收](../results/checks/teacher_evaluation_acceptance_20261018_v1/验收报告.md)。正式复核结果现已补充：43、44 各 100 对，平均差 +0.077、+0.202，区间均跨零，见 [结果分析](../results/evidence/navigation/teacher_return_review_20261018_v1/analysis_20261018/固定教师复核分析.md)。本轮已按封顶规则结束，下方命令保留作执行记录，不需原样重跑。完整 `fixed_targets/*.pt` 仍保留在训练机器。

## 1. 本轮只回答什么

固定已经学得的两个教师，只更换执行评价场景，检查此前教师收益或损失能否重复出现。43、44 是同一个旧 Actor 下的方向训练数据种子，不是两个完整训练种子。

教师在每个新输入上计算 `softmax(log(old(x)) + eta * direction(x))`。冻结的是旧 Actor、方向网络、步幅及输入处理规则；历史输入随各自轨迹正常更新，每回合重置，不能把历史训练批次上的概率表当作新轨迹策略。

本轮新增训练数据采集、方向优化、Actor 优化、Critic 优化次数均为零。只创建旧 Actor 和方向网络，直接调用原回合执行函数，不创建训练 Runner、Collector 或优化器。沿用固定包中的任务、人数、折扣率、评价上限和步幅，不重新训练方向、不拟合 Actor、不调整 η。

## 2. 执行前固定的协议

| 项目 | 本轮约定 |
|---|---|
| 教师 | A0 / N64 / U128 的数据种子 43、44，各加载自己的固定包 |
| 场景种子 | `20261019`；原发现阶段为 `20261018` |
| 数量 | 每个教师 100 对；每对分别执行一次 old、一次 teacher |
| 单回合上限 | 从原配置继承 1,000 联合环境步；成功提前结束时计实际步数 |
| 评价预算上限 | 每个教师 200,000 步，两者合计 400,000 步 |
| 配对 | 一对内相同重置种子及逆 CDF 动作随机数流；各策略仍按自己的概率选动作 |
| 主要指标 | 100 对实际折扣回报差 `J_teacher - J_old` 的均值 |
| 主要区间 | 完整回合对重采样，50,000 次 percentile bootstrap，双侧 95% 区间 |
| 停止规则 | 跑满预定 100 对，不按中途收益停止或追加样本 |

43、44 使用相同的新重置场景，动作随机数还依赖各自数据种子。分别报告两个教师，不能把它们当作 200 个独立重置场景或独立训练重复。区间只描述固定教师在这组评价协议下的抽样不确定性，没有做两个教师的联合推断校正。

保留旧 40 对作为发现阶段数据，新的 100 对是主要复核结果，不与旧结果混合后挑选更有利的区间方法。统计单位是完整回合对，不拆成机器人或时间步。

## 3. 在保有原始固定包的训练机器执行

在包含 `manifold_project` 的项目根目录运行，使用安装了本项目依赖的 Python 环境。以下是完整 PowerShell 命令块，没有 `$py`；如果项目根目录不同，只调整第一行。两条评价依次执行。

本工作区根目录为 `D:\manifold`；43、44 的历史 manifest 记录训练机器根目录为 `D:\manifold\manifold`。若训练机器仍使用该布局，将下面第一行改为 `Set-Location D:\manifold\manifold`，其余相对路径不变。

```powershell
Set-Location D:\manifold
$targets = "manifold_project/experiments/results/evidence/navigation/actor_fit_e1_confirm_20261018_v1/a0_s43_44_u128/fixed_targets"
$review = "manifold_project/experiments/results/evidence/navigation/teacher_return_review_20261018_v1"

# 数据种子 43 的固定教师：100 对新评价回合。
python -m manifold_project.experiments.cooperative_navigation.diagnose --mode teacher-eval --fixed-target "$targets/data_s43_direction_u128.pt" --output "$review/s43" --evaluation-episodes 100 --evaluation-seed 20261019 --device cuda --allow-duplicate-openmp

# 数据种子 44 的固定教师：同一组新重置场景，100 对评价回合。
python -m manifold_project.experiments.cooperative_navigation.diagnose --mode teacher-eval --fixed-target "$targets/data_s44_direction_u128.pt" --output "$review/s44" --evaluation-episodes 100 --evaluation-seed 20261019 --device cuda --allow-duplicate-openmp
```

任一命令末尾加 `--dry-run` 会读取并校验固定包，打印计划；不执行回合、不创建输出。重点核对 `data_seed` 为 43/44、`saved_direction_updates=128`、`eta=0.1`、`evaluation_pairs=100`、`evaluation_horizon=1000`、`maximum_evaluation_steps=200000`，以及所有新增训练成本为零。dry-run 不验证 CUDA 的实际执行。

不传 `--seeds`、`--eta`、`--actor-lrs`、`--fit-epochs` 或方向预算参数；该模式会拒绝这些覆盖。也不使用 `--mode fit --fixed-target`，后者仍会重新拟合 Actor。

输入必须是当时保存的完整固定包。当前仓库中的 `fit_candidates/*.pt`、源训练 `final.pt` 均不能替代它。缺少固定包时，先在原训练机器定位原文件；重新生成方向不能称为同一个历史教师的复核。固定包无需上传 GitHub。

| `data_s43_direction_u128.pt` | `7a941d224dc3f36c6d6a0a2237fbcde23f757cc369cc2a63a1cf80e7d7a12fce` |

## 4. 输出与记账

每个教师单独输出以下文件；正式结果留在 `evidence/navigation`，工程测试留在 `checks`。

| 文件 | 内容 |
|---|---|
| `manifest.json` | 预定协议、来源与模型哈希、代码指纹、运行状态、实际步数和耗时；新增训练成本单列为零 |
| `effective_evaluation_config.json` | 继承任务参数后的实际执行配置 |
| `evaluation_episodes.csv` | 仅 old、teacher 的逐回合指标、重置/动作种子及实际步数 |
| `paired_gains.csv` | 完整回合对的回报差、成功标记及双方步数 |
| `diagnostics.csv` | 完成全部回合后的教师汇总、主要配对区间 |
| `summary.json` | 同一汇总，加正负数量、分位数、最差 5 对及其负损失贡献 |

正式分析要求 `status=completed`、`completed_pairs=100`、`completed_policy_episodes=200`、`source_models_frozen=true`、`input_unchanged=true`。实际 `evaluation_steps` 同时作为 `diagnostic_steps` 记录，不并入新增训练样本；两次运行的实际步数相加即可得到本轮成本。

控制台每 10 对输出完成数量与步数。程序在每个策略回合结束后保存记录，并对可捕获中断记录未完成回合的已执行步数。进程被强制终止或断电时只能保留最近写盘记录。此模式暂不提供断点恢复；中断目录保留，不覆盖，重试使用新目录并保留失败运行成本。中断结果不能作为已完成的 100 对复核。

## 5. 结果出来后如何行动

| 新结果 | 后续行动 |
|---|---|
| 44 或两个教师的负收益得到新的清楚支持 | 优先排查方向估计、标签与有限步幅链路；不能直接归因为泛化失败，也不能归咎于 Actor 拟合 |
| 均值接近零、区间仍较宽 | 结束本轮复核，允许有预算上限的短训练探索；不继续追加评价，也不声称已证明安全 |
| 新结果支持正收益 | 进入短训练，检查是否能累积为学习进展 |
| 两个教师表现不同 | 分别报告，保留差异，不只挑较好的教师代表整个方法 |

报告均值、主要区间、完整逐对回报差、正负数量和大损失贡献。中位数或多数场景改善不能替代期望折扣回报目标，不能删掉少数损失大的场景。一次固定步幅下的负收益仍不能区分方向、GAE/自举标签与步幅的作用。

本轮最多完成这一次预定复核；它用于决定后续排查重点，不要求先取得显著正收益才能继续研究。当前不重跑全部训练，也不同时更改方向损失、网络、奖励或终止规则。
