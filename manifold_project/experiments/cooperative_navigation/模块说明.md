## 2. 输入与内存数据

原生 16 维观测：自身速度 2、自身位置 2、最近地标相对位置 4、最近其他机器人相对位置 4、对应通信 4。N=2 缺邻居时补零。排序/补齐由锁定 MPE2 实现；槽位不表示固定实体身份。

每帧 `[obs(16), onehot(previous_action)(5), valid(1)]`；首次过去动作填零，历史不足部分valid=0。持续任务8帧展平为176维，不加倒计时。当前动作只在下一步进入历史，集中状态不进入Actor。旧finite_horizon模式保留t/100和177维输入，旧checkpoint缺少task_mode时按旧模式读取。

源Critic读4个原生观测拼接，共64维，不称为完整全物理状态。IPPO Critic读本地176维，预测团队回报，但末端价值按各机器人自己的本地历史估计。迁移只用Actor，不调用随人数改变输入维数的集中Critic。旧有限时域维数分别为65/177。

| 内存张量 | 形状（E 独立采样窗口，T 时间，N 机器人） |
|---|---|
| x | E×T×N×176 |
| state | E×T×64 |
| actions | E×T×N |
| mu（冻结实际概率） | E×T×N×5 |
| reward（团队奖励） | E×T |
| terminated / truncated（原生标志） | E×T，bool |
| final_x / final_state（reset前） | E×N×176 / E×64 |
| advantage | E×T×N |
| value_target | 集中 E×T；本地 E×T×N |

最后一个奖励进入回报；持续任务超时补入冻结旧Critic的末端价值。`done = terminated or truncated`只用于决定采样结束和reset，不能作为bootstrap的屏蔽条件。真正终止时末端价值为零；GAE的递推在两种结束处都切断。物理位置只用于诊断，不附加到本地输入。

持续任务的目标为 `G_t = sum(k=t..T-1, gamma^(k-t)*r_k) + gamma^(T-t)*V_old(s_T)`。IPPO将s_T替换为各自final_x。配置的mc名称保留，但此时实际是带bootstrap的多步回报，不是完整无限轨迹的无偏MC。GAE使用 `delta_t = r_t + gamma*(1-terminated_t)*V_old(next_t) - V_old(t)`，其递推系数还乘 `1-(terminated_t or truncated_t)`。旧finite_horizon模式在目标计算时将期限视为任务终点，不改写采样器保存的原生标志。

## 3. 方向方法的实现

Actor 为 128×128 tanh MLP、5 logits；实际 `p=(1-beta)*softmax+beta/5`，beta=0.02。方向网络独立，`q=q_max/2*(tanh(z)-mean(tanh(z)))`，零和且有界。所有算法使用同一 Actor 家族。

定义 `score=q_taken−sum(mu*q)`，`fisher=sum(mu*q²)−sum(mu*q)²`。方向 loss 为 `weighted(quadratic−2*A*score)`，ours 用 fisher，sampled 用 score²。检查仍使用解析 Fisher 项；二者只替换训练二次项。权重按 minibatch 的 `gamma^t/(E*N*sum_t gamma^t)` 归一化。

默认标签 `G−V_old`，不白化、不截断。旧 critic 在本轮开始冻结，拟合 live critic 后独立方向检查依然使用旧副本。每个检查回合先做时间折扣和机器人平均，再对独立回合用 float64 求均值，严格大于零才通过。

目标 `softmax(log(mu)+eta*q)`；旧概率、标签、目标 detach。候选从 old Actor 出发，拟合 `KL(target || candidate)`；记录均值、p95、最大 KL、目标低于 Actor 概率下限的比例。第二候选 eta 减半，从同一个 old 和新 Adam 开始。

回报检查旧/新各采一组独立窗口。持续任务均使用同一冻结旧Critic补入各自末端价值，代理分数均值差严格大于零才接受；这近似“H步执行后接旧价值”，含Critic偏差，不是候选无限期真回报的保证。events同时记录score_kind、代理分数和实际窗口奖励和，便于分辨预测贡献。旧有限时域仍只比较实际奖励和。去方向检查不采该用途窗口；去回报检查接受首个有效候选并取消回报驱动回退；fit_quarter使用ceil(actor_epochs/4)。非法概率或NaN属于异常，不伪装成普通拒绝。

N-A5的 `no_checks` 同时关闭方向检查与回报接受/回退模块，保留解析方向目标、Critic和首个候选的完整拟合，直接提交数值有效候选。`direction_check_enabled`、`return_check_enabled` 共同控制预算预留、实际采样及汇总计数，检查成本与次数均为0；不存在隐式的第二候选或替代接受门槛。

## 4. MAPPO/IPPO 适配

二者共享 Actor、团队奖励、混合概率、折扣权重与终点，区别是集中/本地 critic。GAE lambda=0.95，默认批内优势标准化，PPO ratio 按单机器人实际采样动作概率计算，不乘成联合比值。clip=0.2、熵系数 0.01、10 epochs。

本实现统一用上述多步回报作为Critic回归目标，包括GAE策略标签时，价值损失为加权MSE×0.5；旧模式才是末端为零的有限MC。没有value clipping、学习率衰减或KL早停。这是协议适配的共享策略PPO，不宣称复现官方所有细节或性能。日志ppo_kl/clip_fraction来自最后一个优化minibatch，不是整批总体统计。

## 5. 优化与随机流

Actor/critic 权重跨轮延续，critic Adam 与 PPO Actor Adam 的动量保留。方向每轮按派生种子重初始化，方向和候选 Adam 重置。minibatch 按完整回合排列，默认每批 4 回合。记录裁剪前后梯度范数和更新次数；不保存逐梯度文件。

训练 reset 与动作分别按 condition、seed、用途、回合计数派生。初始化、方向初始化、minibatch 排列分开；评价使用独立命名空间。源网格可共用 reset 与均匀随机序列减少噪声，动作按 condition/训练 seed 隔离，不消耗训练 RNG。评价结果不反馈给训练接受。

Collector 分别记录 train、direction_check、return_old、return_candidate。联合一步不乘人数。默认最低轮次预留为完整/sample/fit_quarter 4000、去方向 3200、去回报 2400、PPO及no_checks 1600 步；方向拒绝实际只花 2400，但不会事后据此降低预留门槛。第二候选单独检查剩余预算。

## 6. 保存、恢复与网格评价

final.pt 包含网络、优化器、计数、CPU/CUDA RNG、曲线、轮次摘要、历史 best 和可选审计候选。原子替换确保保留最后完整轮次，Windows 短暂占用会重试。events 追加账目，恢复时将 checkpoint 后已预留/已采成本单列，避免超预算。

例：旧提交成本 6400、新轮完成成本 10400，网格 8000 仍用旧 Actor；12000 才可能使用新 Actor。AUC 按节点左端矩形计算，禁止未来插值。B 节点使用最后提交策略，即使还有不足一轮的剩余预算。

best 只按独立源 J 选取，供开发诊断，不影响接受规则；主结果和迁移用 final。`train_seconds` 测量采集、标签、优化、检查及其中日志开销，不含独立评价、轮次 checkpoint 和套件汇总 I/O。比较完整作业耗时应另计这些开销。

每轮 `info` 同时保存训练批回报、Critic MSE和更新秒数，写入既有commit事件与checkpoint轮次记录。Runner在checkpoint提交后打印状态，再调用可选监控回调；绘图只读这些记录，不消耗采样或训练随机流，不计入训练秒数。监控图原子替换，图片写入失败会打印原因，后续刷新重试，不使已提交训练失败。命令与间隔只在运行说明维护。

N-D 固定 ours/no_return_check 第 1/5/10/20 完成轮次首候选；包括拒绝候选，无候选不顺延。旧/新共享独立 reset、动作流分开；逐 reset 差值区间不是训练种子区间，未经多重比较校正，不代表全部更新退化率。N-L 单独对齐标签和标准化，不暗改主协议。

持续任务下N-D目前仍审计实际窗口J，和含bootstrap的接受分数不是同一量，因此supported_false_rejection留空，不能据此宣布持续目标上的误拒绝。长期占位由独立长窗口评价检验，命令见运行说明。
