## 2. 任务边界与输入

task_horizon=500是任务期限，horizon=100仅用于训练配额。原生terminate_on_success=False，由Navigation在原生step之后依据统一的全覆盖判据结束任务；原生动力学和奖励不变。原生max_cycles=500的超时在新任务中表示明确的截止失败。

| 边界 | terminated | truncated | 价值目标 |
|---|---|---|---|
| 首次同时全覆盖，含最后一步成功 | True | False | 最后奖励保留，后续价值0 |
| 截止仍未全覆盖 | True | False | 最后奖励保留，后续价值0 |
| 训练配额用完但任务未结束 | False | True | 实际末端观测bootstrap，GAE切断递推 |
| 其他步骤 | False | False | 正常递推 |

初始已全覆盖为零步成功。独立评价和检查运行完整任务；训练最后片段截断不记为任务失败。后续采样reset并清空历史，不将下一场景奖励串入上一条轨迹。

新Actor输入8×(16维观测＋5维自身上一步动作＋1维有效标志)＋t/task_horizon=177维；剩余时间可由1−该时钟得到。源集中Critic为4×16＋时钟=65维，IPPO Critic为各自177维历史。N变化不改变Actor输入。旧continuing模型按176/64维原配置加载，不填零硬接新网络。

方向方法Actor为两层128单元tanh MLP，5个logits，概率=(1−beta)softmax＋beta/5。独立方向网络同宽，输出有界零和q，默认q_max=1；每轮重新初始化，不使用Polyak软更新。Critic为两层128单元MLP、标量输出。评价用的物理位置不额外进入Actor。

## 3. 完整方法的一轮

1. 冻结旧Actor/Critic，采1600个真实联合步；任务结束后reset，最后未完成片段保存末端观测。
2. 计算冻结MC/GAE标签，更新Critic；不用更新后的Critic改写本轮方向标签。
3. 训练新方向网络；sampled仅把解析方差二次项替换为采样score平方。
4. 另采8个完整任务做方向检查，拒绝时Actor保持原样。
5. 用softmax(log(mu)+eta*q)构造冻结目标，拟合候选Actor。
6. 旧策略、候选分别采8个完整任务，比较实际终止回报J；严格改善才接受，否则eta减半，从旧Actor重拟合，最多2次。
7. 检查实际步数计入源预算，提交后维护final、诊断best和监控图。

no_checks删除两检查并采用首个有效候选；no_return_check删除回报接受及回退；no_direction_check只删除方向检查。独立报告评价不参与训练接受。

本地批次E×Tmax×N附带valid/lengths，padding不参与标签、损失、标准化和误差统计。折扣损失按共同task_horizon归一化，吸收状态贡献零，不按每条实际长度归一化。minibatch_episodes仍按轨迹分组，实际优化次数随回合数变化并如实记录。

## 4. MAPPO/IPPO适配

共享固定作者提交de66d7a4b23fac2513f56f96f73b3f5cb96695ac，vendor仅改导入命名空间。PPO、GAE、ValueNorm、价值裁剪和Huber不重写；集中/本地Critic区别保留。

首达批次只把valid transition按轨迹顺序打包为一条buffer lane：1600团队步即6400个agent样本。内部reset的success/deadline mask为0；仅批末采样截断bootstrap。padding从不送入作者优势标准化、ValueNorm或优化器。MAPPO广播团队价值，IPPO保留各机器人自己的价值。

作者PPO保留LayerNorm、正交初始化和原生Categorical，不添加beta混合。作者MPE配置为Tanh、128宽度，优化参数见运行说明。旧持续任务仍使用独立窗口lane。不能声称各算法网络和更新细节完全相同，或将整算法差异归因于单个模块。

## 5. 评价与恢复

评价只累计实际终止前奖励，不调用Critic。best按(success_rate, −restricted_mean_steps, −collision_pairs_total)排序，仅作诊断；主表和迁移固定使用final。评价实际步数逐回合累加，N=4迁移复用final源评价。

预算节点使用不超过节点的已提交策略；success_AUC与回报AUC均作左矩形积分。训练和评价使用隔离的随机流，目标规模不用于选参。

检查点保存模型、优化器、随机状态、采样计数、预算账、ValueNorm和评价历史。恢复要求同任务、配置、实现、依赖和源码。中断未提交采样按最大预留保守计费，单列成本；预算不足下一轮最大预留时停止并记录unused_budget。只保留best/final，常规日志仍为单个events.jsonl。
