# 当前协作导航协议审查与四方法试跑

日期：2026-09-25。对象为统一入口 `python -m manifold_project.experiments` 下的N-C/N-T，不包含历史套件配置。当前判断：工程协议可以开展小预算试跑；跨规模理论充分条件尚未得到证明，不把可执行性测试当成迁移保证。

## 1. 审查结论

| 项目 | 当前实现 | 判断与边界 |
|---|---|---|
| 源与目标 | 源4机器人/4目标；目标2、6、8机器人及同数目标；相同初始区域 | 数量与密度一起变化；不能称为仅改变人数而其他任务难度不变 |
| Actor输入 | 自身位置/速度/剩余时间，全部目标相对位置，全部同伴相对位置与原生通信字段 | full模式无最近邻截断；未把同伴速度或Critic全局状态私自加入Actor |
| 可变实体数 | 共用实体编码、关系注意力、按实体类型聚合，固定5动作头 | 参数尺寸不依赖人数；集合压缩不保证信息无损，也不保证源经验覆盖目标需求 |
| CTDE | Actor用各自环境观测；Critic在源训练使用全局位置、速度及时间 | CTDE兼容，但Actor具有全范围位置感知，不能宣传为有限视野导航；Critic只在固定源人数训练 |
| 动作 | 原生5离散动作，静止/左/右/下/上 | 沿用MPE动力学，无新增动作屏蔽或目标指派器 |
| 奖励 | 原生agent奖励取均值，local_ratio=0.5 | 未增加成功奖励；距离部分随目标数改变量级，不跨规模直接按原始回报排名 |
| 成功 | 首次同时覆盖全部目标即终止 | 每个目标到最近机器人距离<0.1；不是严格一对一匹配，也不是到达后继续驻留 |
| 截止时间 | 每回合最多200联合环境步；未成功则deadline终止 | 本任务是有限时限，剩余时间进入观测；截止处不bootstrap，不能解释为无限持续任务的人为采样截断 |
| 采样 | 完整任务回合，变长回合有valid掩码 | 不将成功后padding作为真实训练样本；初始成功单独记录 |
| 预算 | 训练、检查、训练内源监控按真实联合环境步计入 | 预算尾部不足完整批次时可留下余额；训练后报告评价单独记账，不用于选更新 |
| Critic | 与Actor相关更新使用同一训练批次中的冻结旧Critic标签，再训练Critic | 不是pair的独立基线采样方案；不能搬用pair每轮采样比例 |
| 检查 | AN完整含两项，核心版两项关闭；DA含回报检查；PPO不使用两项门控 | 导航回报门控使用严格均值比较，不能把pair平局放行统计直接套入导航 |
| 冻结迁移 | final.pt为主；仅恢复Actor，按目标人数动态编码；评价前后核对参数不变 | 不构造目标Critic、不微调、不按目标挑best；best只来自源监控 |
| MAPPO | 固定作者实现的优化与GAE/ValueNorm流程，替换为共用实体Actor | 是适配实体输入的MAPPO-E，不是未经修改的作者原网络 |

代码依据：`applications/envs/navigation.py`、`cooperative_navigation/envs/navigation.py`、`models/entities.py`、`models/deployment.py`、`training/collector.py`、`training/runner.py`、`training/author_ppo.py`、`current_protocol.py`、`applications/evaluation.py`。

本次四方法范围内未发现必须修改动力学、观测或终止代码才能试跑的问题；主要工作是固定可比较配置、明确理论边界并补充四方法集成验证。本次不宣称整个历史入口或其他未选消融均已完成同等审查。

## 2. 四种配置

配置位于 `experiments/configs/navigation_trial/`。

该目录是本轮四方法试跑的唯一配置入口。未接入文档/测试的另一套 `navigation_pilot_v1` 已清理，其检查与评价样本数不同，不能和本轮混用。`cooperative_navigation/configs/source.json`及profile文件仍供底层Runner加载，属于基础配置层，不是这四份实验配置的重复副本。

| 文件 | 方法 | 方向检查 | 回报检查 |
|---|---|---|---|
| an_core.json | AN核心版 | 关 | 关 |
| an_checked.json | AN双检查版 | 开 | 开 |
| da_checked.json | 完整DA | 不适用 | 开 |
| mappo.json | MAPPO-E | 不适用 | 不适用 |

共同设置：种子40，源预算262144联合环境步，源人数4，时限200，hidden=128、heads=4、relation_layers=2，full实体输入，Actor学习率3e-4、Critic学习率1e-3、方向学习率3e-4，训练批次16个完整回合。方向/Actor各16个优化epoch，Critic10个，PPO10个，batch划分保持公共设置；不宣称优化次数或计算时间完全相同。

本轮统一label_mode=gae，gamma=0.99、lambda=0.95，减少方向方法/DA与作者PPO标签族的差异。方向标签因此含Critic近似和GAE偏差，不能套用精确优势下的无偏估计保证。MAPPO仍保留自己的优势标准化、ValueNorm等算法组件，不能宣称各方法的训练目标完全相同。

检查开启时每批16回合。这个值是试跑工作设置，不是已验证可靠或最优值，也不照搬pair的512回合。完整AN一个完整更新的保守采样预留为12800步、完整DA为9600步、核心AN/MAPPO为3200步；这些按最大200步估算，回退尝试会增加成本。各组预算相同，允许更新次数不同。

源监控每65536步一次，每节点8回合（含初始/最终，共5节点，保守预留8000步）。最终报告评价20回合。关闭额外fit_probe采样，避免只有AN增加诊断开销。每5轮覆盖刷新训练总图。单种子、少量评价只用于检查流程与初步学习，不作算法排名或收敛结论。

## 3. 小规模试跑命令

在直接包含manifold_project的目录，使用此前已有PyTorch/MPE2环境运行。这里的pilot不会覆盖--config中预算。CUDA命令需运行电脑确有可用CUDA；本机工程核验用CPU，不代表验证了其他电脑的CUDA依赖。

```powershell
python -m manifold_project.experiments --experiments N-C --profile pilot --methods AN --config manifold_project/experiments/configs/navigation_trial/an_core.json --device cuda --output manifold_project/experiments/results/navigation_trial/an_core --plot
python -m manifold_project.experiments --experiments N-C --profile pilot --methods AN --config manifold_project/experiments/configs/navigation_trial/an_checked.json --device cuda --output manifold_project/experiments/results/navigation_trial/an_checked --plot
python -m manifold_project.experiments --experiments N-C --profile pilot --methods DA --config manifold_project/experiments/configs/navigation_trial/da_checked.json --device cuda --output manifold_project/experiments/results/navigation_trial/da_checked --plot
python -m manifold_project.experiments --experiments N-C --profile pilot --methods MAPPO-E --config manifold_project/experiments/configs/navigation_trial/mappo.json --device cuda --output manifold_project/experiments/results/navigation_trial/mappo --plot
```

四组无相互依赖，共用一张GPU时建议依次运行以免资源竞争。没有可用CUDA则将device换成cpu。配置文件需要同步到实际训练电脑。不要用smoke替代这组命令：smoke会缩短任务和网络，只是工程检查，不是上述200步任务试跑。

## 4. 源训练完成后的轻量冻结评价

可先对核心AN核对目标人数2/6/8的加载和执行，其余三组同理替换配置、source和method：

```powershell
python -m manifold_project.experiments --experiments N-T --profile pilot --methods AN --config manifold_project/experiments/configs/navigation_trial/an_core.json --source manifold_project/experiments/results/navigation_trial/an_core --device cuda --output manifold_project/experiments/results/navigation_trial/an_core_transfer --plot
```

此命令只评价20回合/规模，不训练目标策略。正式比较必须评价四组全部方法，不能只展示核心AN的目标结果。成功率、完成时间、最终覆盖率、平均目标距离、碰撞参与率为主要解释指标；同时报告初始成功和截止失败，原始奖励作为补充。目标数据不用于选超参数、源checkpoint或预算。
