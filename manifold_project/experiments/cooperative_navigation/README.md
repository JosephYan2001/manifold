# 合作导航实验

本目录存放 MPE2 `simple_spread_v3` 的环境封装、配置、训练、评价和测试代码。目前完成目录建立，环境尚未安装、封装或训练。

任务配置：源环境 4 个智能体、4 个地标；固定观察最近的 2 个其他智能体和 2 个地标；5 个离散动作；100 个联合步；团队奖励取原生个体奖励均值。冻结后评价规模 3、6、8。

后续按[三个实验环境构建指南](../../docs/三个实验环境构建指南.md)第 5 章实现，重点核验 MPE2 版本、最近邻观测、共同奖励和有限时域终点。

各环境分别维护依赖文件。此目录的依赖锁定文件将在实际完成 MPE2 版本核验后生成。
