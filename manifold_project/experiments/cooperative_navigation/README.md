# 合作导航实验

本环境承担多步协作任务中的算法比较、机制诊断和经验冻结迁移。研究目标是**首次同时覆盖全部目标即完成**。任务、信息协议、实验组及理论缺口统一见[总实验方案](../../docs/策略流形研究设计.实验方案.md)；跨模块边界见[项目总体架构](../../docs/项目总体架构.md)。

| 文档 | 内容 |
|---|---|
| [实现说明](实现说明.md) | 当前任务、观测、网络、训练流程与尚未实现的接口 |
| [实验运行说明](实验运行说明.md) | 配置预检、恢复、评价、回放，以及输出和指标解释 |

当前代码仍只输入最近 2 个机器人和最近 2 个地标。显式启用 `first_arrival` 时，Actor 为 177 维，源集中 Critic 为 65 维，训练按固定真实步数配额采样。它尚未实现总方案中的完整目标信息、完整回合训练和同快照三策略诊断。

正式协议尚未冻结；现有配置用于工程参考和回归检查，不是待执行的新实验清单。模型能在不同规模运行只说明接口兼容；固定源目标数加完整目标有效位仍存在总方案列明的覆盖反例。
