# 合作导航：实验设计与结论边界

更新：2026-09-20。本文维护环境、研究问题、比较组和证据要求。当前开发命令与候选参数只在[实验运行说明](实验运行说明.md)维护；代码细节见[模块说明](模块说明.md)，指标定义见[训练指标与调参说明](训练指标与调参说明.md)。正式参数尚未冻结。

本设计落实[总体实验清单](../../docs/实验执行矩阵.md)，方法与统计共识见[共同执行协议](../../docs/实验执行矩阵_详细协议.md)。旧有限时域源开发数据已按用户要求清理；当前首先按持续任务从头开展同配置长预算学习能力对照，再研究检查消融。实测判断保留在results，不将研究预期当作已证实结论。

## 1. 这个环境要回答什么

成对协作环境已经说明：局部方向估计改善不必然转化为完整训练优势；检查可能消耗大量交互而没有展示保护收益；Actor 拟合预算可能有冗余。导航应在多步、部分观测、连续物理状态下检验这些现象，而不是重复可枚举任务的数学核验。

对应证据与实验映射见[成对论文结论与后续验证](../pair_coordination/results/论文结论与后续验证.md)第 5 节。成对任务的高阈值效率、人数不变性、16 epochs 设置和精确退化判断均不能直接移植为导航结论；导航以自身独立评价与预定审计为依据。当前开发候选与历史pilot分开记录。

| 研究问题 | 需要的证据 | 不足以支持结论的现象 |
|---|---|---|
| Q1：在相同源交互预算下是否更有效率？ | 与 sampled、MAPPO、IPPO 比较独立评价回报曲线和覆盖表现，同时报告耗时 | 训练回报较高、网络更新次数更多或只挑最佳种子 |
| Q2：解析二次项是否带来训练收益？ | 完整方法与 sampled 除二次项外完全一致的比较 | 两个不同 loss 的绝对数值大小 |
| Q3：方向与回报检查是否值得其成本？ | 去检查消融、实际采样账目、检查决定及独立评价变化 | 接受率高、检查均值为正就称“真实不退化” |
| Q4：Actor 拟合是否成为瓶颈？ | 1/4 拟合预算下的 KL、回报和计算成本 | KL 小就认定回报更好 |
| Q5：冻结策略能否适应团队与任务数量变化？ | 相同 final actor 在各目标规模的独立评价，与各基线同规模比较 | 输入维度不变、人数增加后原始团队奖励变化 |

论文中主张的强度随结果调整。零差异、检查更慢、迁移下降都属于有效结果；不通过删除种子或事后挑环境构造优势。

## 2. 固定环境、奖励和终点

### 2.1 环境协议

选用 Farama MPE2 Simple Spread 的 Parallel API，已锁定并本地核验发行版 mpe2==1.1.1。接口提供离散动作、最近邻观测和课程/提前结束开关。[官方接口](https://mpe2.farama.org/environments/simple_spread/)

| 项目 | 本实验规定 |
|---|---|
| 源规模 | N=4：4 个机器人、4 个地标 |
| 动作 | continuous_actions=False，5 个离散原生动作，不额外动作掩码 |
| 本地可见邻居 | 最近 2 个其他机器人、最近 2 个地标 |
| 奖励混合 | local_ratio=0.5 |
| 采样窗口 | 100 个联合步，每轮动作同时提交；超时后重置，但价值不归零 |
| 成功提前结束 | terminate_on_success=False |
| 课程与缩放 | curriculum=False；dynamic_rescaling=False，均显式传入 |
| 重置与物理参数 | 锁定版本的原生重置和动力学，不按方法或目标规模改动 |
| 折扣 | gamma=0.99，训练与主评价一致 |
| 部署策略 | 从训练概率分布随机采样；贪心动作只能作为额外标明的评价 |

最近邻是数量限制，不是固定半径感知。远处实体也可能进入列表。规模变化时邻居数始终为 2。原生字段顺序、补齐、同距离排序及通信槽含义，以锁定源码和实测为准。当前在线说明与源码对部分默认值的展示存在差异，因此不能依赖省略参数后的默认行为。[环境源码](https://github.com/Farama-Foundation/MPE2/blob/main/mpe2/simple_spread/simple_spread.py)

### 2.2 共同团队奖励

所有方法使用同一个团队奖励：对原生返回的 n 个个体奖励取均值，不改为求和，也不让 IPPO 使用不同的个人奖励。

令机器人位置为 p_i，地标位置为 l_k，唯一碰撞对集合为 C_t。需通过源码和单步测试核验以下分解：

```text
g_t = -sum_k min_i ||p_i - l_k||
c_i,t = -sum_{j != i} 1{机器人 i 与 j 碰撞}
r_team,t = (1 - 0.5) * g_t + 0.5 * mean_i(c_i,t)
         = 0.5 * g_t - |C_t| / n
```

碰撞条件使用原生机器人半径和距离判据，不能用覆盖阈值替代。MPE2 1.1.1 在 N=2/3/4/6/8 的 100 步固定动作回合已通过此奖励分解验收。若后续换版后与公式不一致，先解释并修订协议，不能悄悄修改奖励。

### 2.3 持续任务、超时与评价窗口

研究目标是机器人持续导航并保持目标覆盖，采用折扣持续任务 `task_mode=continuing`。达到覆盖阈值不是终止条件，机器人仍需维持位置并避免碰撞。第100步只是采样上限：原生 `terminated=False, truncated=True`，分别保留两个标志以及 reset 前的最终观测/历史。最后奖励必须计入目标，末端还需加上冻结旧Critic的价值；真正终止时才归零。GAE在reset边界切断优势递推，不能串入下一段轨迹。

训练继续按独立100步窗口采样，每段后reset并清空历史；这是带超时bootstrap的采样实现，不是让同一个物理场景跨轮永久运行。训练目标近似持续折扣价值，仍受Critic误差和有限状态覆盖影响。独立源评价的J保持为实际100步奖励和，不补预测值；完成后对final策略另做500步不reset的评价，检查平均覆盖、后半窗口覆盖和全覆盖比例，不能用第100步的单点覆盖证明持续占位。

参考实现需区分版本：[旧MAPPO的MPE封装](https://github.com/marlbenchmark/on-policy/blob/main/onpolicy/envs/mpe/environment.py)按world_length返回done，[其MPE Runner](https://github.com/marlbenchmark/on-policy/blob/main/onpolicy/runner/shared/mpe_runner.py)直接生成结束mask，因此不能称所有MPE基线都已正确处理持续任务超时。本次采用[Gymnasium的结束语义](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)和[Stable-Baselines3的超时bootstrap原则](https://stable-baselines3.readthedocs.io/en/master/_modules/stable_baselines3/common/on_policy_algorithm.html)，由所有算法共同执行。

旧协议 `finite_horizon` 明确定义100步任务终点、价值为零，并包含时间输入；仅用于历史复现。旧checkpoint缺少task_mode时按该定义读取。旧数据和模型已按用户要求清理，新协议从头训练；本次改变任务目标和输入，不能将未来观察到的差异全部归因于一个done变量。

距离奖励的有效上下界不能由显示窗口或样本极值推断。当前使用empirical检查，不宣称Hoeffding安全保证；持续目标还含估计的末端价值，若以后引入置信保证，必须重新论证奖励、价值和检查分数的界。

## 3. 输入与网络必须一致

### 3.1 Actor 与方向网络

每个机器人只读取自身最近8步获准观测与过去自身动作。历史元素定义为 `(o_i,s, onehot(a_i,s-1), valid_s)`，s=t-7…t；首次动作前的前一动作填零，reset之前的历史全部补零且valid=0。不附加t/100，避免把人为采样期限当作任务倒计时；当前动作a_i,t不得进入当前输入。

每步观测原生维度记为d，持续任务输入维度为 `8*(d+5+1)`。不要直接套用文档默认N=3时的维度；在3/4/6/8人实测形状、字段与固定维度。最近邻槽位表示距离排序，不保证跨时间是同一个实体。所有方法共用同一历史构造器。

方向方法的Actor为两层128单元tanh MLP，五维logits，共享参数，`pi=(1-beta)*softmax(logits)+beta/5`、beta=.02。作者MAPPO/IPPO共同使用两层128单元MLP、LayerNorm、正交初始化和原生Categorical，不加beta混合；默认ppo_activation=relu，新增author_mpe候选为tanh，各自Actor/Critic一致。各方法使用自身实际采样分布计算log_prob和熵。

初始方向网络：独立的两层 128 单元 tanh MLP，输出五维 z；令 `u=tanh(z)`，`q=(q_max/2)*(u-mean(u))`，q_max=1，以保证零和且每个分量绝对值不超过 q_max。Actor 与方向参数独立，方向训练期间冻结 Actor。

网络使用float32，涉及独立回合汇总的均值和统计区间用float64累积。N=2/3/4/6/8原生观测均为16维，新持续任务8步历史Actor输入为176维；旧有限时域为177维。机器精度和优化稳定性由smoke核验，不继承成对任务全程float64的成本。

### 3.2 Critic 与信息边界

完整方法、sampled、消融和MAPPO使用相同集中字段：源环境state()。MPE2 1.1.1的state()为各机器人原生观测拼接，新持续任务源输入64维，不称为完整物理状态；旧有限时域加时间为65维。均为两层128单元MLP、标量输出，但作者MAPPO保留LayerNorm/正交初始化和ValueNorm，激活函数随PPO候选记录，不能声称网络结构完全相同。

IPPO的价值网络读取与Actor相同的本地历史，各机器人共享价值网络参数，预测团队回报。超时bootstrap分别使用各机器人的最终本地历史价值，不借用集中Critic。集中与本地Critic输入维度不同，因此不能声称全部方法总参数数完全相同；应报告Actor、Critic、方向网络各自参数量。

首版不使用运行中的观测标准化，以免候选更新或迁移时隐式改变策略。若 pilot 确需归一化，必须统一全部方法、只用源数据拟合、包含在 checkpoint，并在检查和目标评价时冻结。评价器为距离/碰撞指标读取物理位置是允许的，但这些字段不得经日志或旁路进入 Actor。

## 4. 训练条件（七个常规条件及一个联合消融）

| 标识 | 条件 | 与完整方法的唯一预定差异 |
|---|---|---|
| ours | 解析方向＋Actor 拟合＋两项 empirical 检查 | 参考方法 |
| sampled | 采样平方方向目标 | 只替换方向损失二次项；线性项、标签、网络、预算及检查一致 |
| mappo | 作者实现的共享本地Actor＋集中Critic PPO | 保留作者GAE/λ-return、价值归一化与裁剪；不做接受检查 |
| ippo | 作者实现的共享本地Actor＋本地Critic PPO | 与MAPPO共用作者训练逻辑；Critic读取各自历史、独立计算末端价值 |
| no_direction_check | 删除方向检查 | 不采方向检查回合，直接进入候选构造；回报检查保留 |
| no_return_check | 删除回报检查 | 方向通过后接受首个有效候选；同时取消回报驱动的步幅回退 |
| fit_quarter | Actor 拟合预算为标准的 1/4 | 仅减少 Actor epochs，方向、critic 和检查不变 |
| no_checks（N-A5） | 同时删除两项检查 | 不采检查数据，保留方向学习及原步长拟合，直接采用首个有效候选；取消回报驱动回退 |

MAPPO/IPPO共同使用[作者源码固定提交](https://github.com/marlbenchmark/on-policy/tree/de66d7a4b23fac2513f56f96f73b3f5cb96695ac)，适配同一MPE2场景、本地历史、团队奖励及持续任务终点。两者Actor和优化设置一致，Critic分别读取集中状态和本地历史；输入维度不同导致Critic参数量不同，不能声称总参数数相等。作者算法模块只改导入命名空间；适配点见[模块说明第4节](模块说明.md#4-mappoippo-适配)。论文标注“基于作者实现、适配统一持续任务协议”，不宣称复现原论文环境与成绩。

## 5. 公平性与归因原则

源环境、奖励、Actor信息、隐藏层宽度、总源预算、评价规则和开发资源保持公平；保留并披露作者网络归一化、激活函数、分布、价值目标和优化细节，整算法成绩差异不能唯一归因于方向模块。公共参数与允许不同的PPO设置见运行说明。eta与ppo_clip均影响更新幅度，但不要求数值相同，也不等价于同一种接受约束。

sampled和检查消融继承选定ours的所有超参数，不单独调参。N-A1/N-A2/N-A3保持单模块变化；N-A5显式作为联合消融，不替代单模块对照。N-A3移除的是整个回报接受/回退控制模块，直接采用首个有效候选；不能将其差异仅归因于回报门槛。N-A4只减拟合预算，属于敏感性实验。

Actor拟合、冻结旧Critic、MC/GAE标签、两项empirical检查、PPO目标和随机流实现统一见[模块说明](模块说明.md)。独立源评价不参与候选接受；检查通过不提供真实回报不下降保证。

## 6. 预算、阶段和种子

### 6.1 预算单位

一次所有机器人联合动作推进计 1 团队步，不乘人数。训练、critic 专用采样（若以后增加）、方向检查、旧策略回报检查、候选回报检查都计入源优化预算 B；重复使用同一数据做 epoch 不重复计交互，但需计优化次数和耗时。

按首版批量，每轮成本为：

| 分支 | 团队步 |
|---|---:|
| 完整方法，一个候选 | 1600+800+800+800=4000 |
| 完整方法，第二个候选也检查 | 5600 |
| 方向检查拒绝 | 2400 |
| 去方向检查，一个候选 | 3200 |
| 去回报检查 | 2400 |
| MAPPO/IPPO | 1600 |
| N-A5去两项检查 | 1600（仍需方向学习和Actor拟合计算） |

所以相同预算下轮数不同是预定结果。整回合计账，不超预算；下一轮预留方法对应最低成本，剩余不足时停止并报告未用预算。回退候选也必须先检查剩余预算。

### 6.2 阶段与种子

| 阶段 | 条件与种子 | 状态或用途 |
|---|---|---|
| 接口 / smoke | N=2/3/4/6/8；七条件seed0 | 验证实现，不能评价性能 |
| 当前长预算源开发 | MAPPO、IPPO、no_checks MC/GAE，seed40，每组先2000万步 | 每50万步评价1024回合；按末段稳定性判断是否继续，不能把预算用完等同收敛 |
| PPO作者参数对照 | author_mpe.json用于MAPPO/IPPO，各seed40、2000万步 | 新增两次训练；与原共同参数候选分开保存，按源开发结果选参，不能单因素归因 |
| 后续复核 | 有依据的改进补41/42，验证完整ours及检查配套，再做正式公平比较 | 完整方法及各模块消融均需新协议结果；先完成当前能力与PPO配置对照 |
| 正式主比较与单模块消融 | 六条件×100–109，共60次 | 冻结共同预算后运行 |
| N-A4敏感性 | fit_quarter×100–109，另10次 | 单独决定是否开展，参考模型复用 |
| N-A5联合消融 | no_checks×100–109，另10次 | 开发阶段先seed40，正式纳入须在冻结前确定 |

所有选参仅使用源开发种子，不使用正式种子或目标规模表现。保存全部候选及选择记录，冻结唯一共同预算、参数、评价和审计计划后再开始正式实验。

早期200万步PPO尚未确认收敛，其终点只用于历史趋势。当前2000万步也不是收敛保证；若末段仍上升，记录未收敛并安排续训，若评价精度不足则优先补评价。四组首先建立长预算能力参照，不将no_checks变体成绩记为完整方法提升。旧有限时域数据、参考模型和诊断已清理；新协议结果状态见[结果索引](results/README.md)。

训练随机流分为初始化、训练 reset/动作、方向检查、回报旧策略、回报候选；用任务标识、训练种子、用途、计数派生。独立评价使用另外的种子空间，不能与训练检查共用。相同训练种子只是配对实验块，不保证不同方法经历相同轨迹。

## 7. 每个实验具体做什么

### N-C：四种算法的正式比较（必做）

- 条件：ours、sampled、mappo、ippo；每种 10 个新种子，统一 B，共 40 次训练。
- 主结果：独立源评价的折扣回报 AUC/B、final 回报；报告平均终点覆盖率与碰撞作为任务解释。
- 图表：回报—总源步曲线及训练种子区间；方法对比表（回报、覆盖、全覆盖率、碰撞、耗时、优化次数）。
- 待检验预期：方向方法可能在学习速度或最终表现上有竞争力，也可能因检查成本落后。若最终相近，重点报告达到覆盖阈值的成本与计算代价，不把微小均值差写成优势。

### N-A1：解析二次项（必做，复用 N-C）

- 直接比较 ours 与 sampled，不新增训练；共享标签、网络、采集量、epochs、检查和评价协议。
- 报告同种子配对 AUC/final 差值、方向检查分数、目标与拟合 KL。
- 导航没有精确本地方向，不能把采样分数命名为“真实方向误差”。若二者无明显差别，结论是该条件下没有发现训练收益，不能靠 loss 数值证明解析项更好。

### N-A2：方向检查的收益与成本（必做）

- ours vs no_direction_check；新增 10 次训练，参考组复用。
- 报告方向拒绝率、候选数、后续回报拒绝率、各用途交互成本及 AUC。
- 待检验预期：若方向不可靠，筛选可能减少无效拟合；若几乎全通过，移除检查可能更有效率。两种结果都应保留。

### N-A3：回报检查的收益与成本（必做）

- ours vs no_return_check；新增 10 次训练，参考组复用。
- 报告采样检查回报差、接受率、独立评价曲线的下降、样本效率及总耗时。
- 预期检验检查是否值得其预算；常规评价曲线只能显示评价节点间变化，不能估计每次更新的真实退化率，更不能称“没有下降即安全”。
- 若需要论文主张“逐次保护收益”，执行下方 N-D 独立审计；否则将结论限定为成本和整体训练表现。

### N-A4：Actor 拟合预算（另列敏感性实验）

- ours vs fit_quarter；新增 10 次训练，参考组复用。
- 标准 16 epochs 时对照为 4；若正式标准在开发阶段改变，则为 ceil(标准/4)，其余配置一致。
- 报告拟合 KL 分布、回报/AUC、梯度更新次数和耗时。预期可能性能近似且更省计算，也可能拟合不足导致性能下降；成对任务的 16 轮结论不直接推广。

### N-A5：两项检查的联合消融与交互影响

| 条件 | 方向检查 | 回报接受/回退控制 |
|---|---|---|
| ours | 保留 | 保留 |
| no_direction_check | 去掉 | 保留 |
| no_return_check | 保留 | 去掉 |
| no_checks | 去掉 | 去掉 |

- 四组共享选定ours超参数、标签、预算、评价协议和训练种子。联合组保留完整方向学习与Actor拟合，不叠加改eta或减少拟合次数。
- 开发阶段补齐seed40四组，在新开发种子复核趋势后再决定正式范围；复用已有同协议参考，不重复训练。
- 联合组直接采用首个数值有效候选，接受率高是定义所致。主证据仍是源J/AUC、覆盖、碰撞、成本和稳定性，可能更快，也可能出现更大波动或退化，不预定有利结论。
- 在同训练种子块内，可计算交互对比 `I = Y_两项保留 - Y_仅方向保留 - Y_仅回报保留 + Y_两项去掉`，Y预先选J或AUC。跨训练种子报告该差值及区间；单种子只能用于开发，不能判断稳定交互。
- 相同源预算下，各组检查与训练的采样分配不同。交互对比反映整套机制在此预算下的综合影响，不能直接等同于门槛的纯数学效应或误拒绝率。若需进一步区分，另行预定匹配训练更新量并报告额外总成本的诊断，不能改写主要同源预算比较。
- 原N-A计划保持原样；N-A5须显式选择。该条件不默认进入N-T主算法迁移或原N-D审计范围。

### N-T：冻结人数迁移（必做，不新增训练）

- 复用 N-C 的 4 方法×10 个 final actor，评价 N=3/4/6/8；N=4 使用相同 final 源评价结果，不重复采样。
- 每模型每规模 200 个独立回合。N=3/6/8 合计 24000 回合、240 万团队步，单独记为目标评价成本。
- 保持原生重置、动力学、100 步时域、邻居数 2、奖励系数和随机策略不变；只改变 N，因此地标数量也同步改变。
- 报告同规模下方法对比，以及每地标距离、覆盖率、唯一碰撞对数、每机器人碰撞数。原始回报跨规模不可单独解释为迁移优劣。
- 无目标 fine-tuning、无目标 critic 更新、无目标观测统计更新；不得按目标结果从 best/final/中间 checkpoint 中挑选。
- 预期是检验经验泛化，不要求人数变化时回报恒定；也不把经验指标当成方向运输定理的验证。

### N-D：独立更新审计（条件必做）

若论文要声称回报检查降低逐次退化或存在误拒绝，预先启用此诊断。仅对 ours/no_return_check，每训练种子第 1、5、10、20 个完成轮次的首个有效候选，保留旧 Actor 和候选、冻结预处理及检查决定；无候选时记缺失，不移动到更有利轮次。

训练结束后，每对策略用200个独立reset种子配对评价；旧/新策略动作随机流分开，全部回合独立于训练检查。按每个reset的候选−旧实际窗口J计算配对区间。区间上界<0为“窗口评价支持的退化”，下界>0为“窗口评价支持的改善”，否则为“不确定”。持续任务的接受分数含末端bootstrap，与这里的有限窗口J不同，因此即使拒绝且窗口差值区间下界>0，也不能直接认定持续目标上的误拒绝；实现中supported_false_rejection留空。若要提出该主张，应预先扩展长期候选审计和对应成本。

最多 2 方法×10 种子×4 对×2 策略×200 回合×100 步=320 万审计步。此为固定轮次诊断，不是全部更新退化率的无偏估计；检查组和消融组的第 k 轮交互成本也不同。候选集合按正式协议预先确定，不能看检查真假后才保存。比较结果以训练种子为重复块，不把所有候选当成独立训练种子。报告逐候选区间时注明多重比较，未经校正不得作总体错误率保证。

### N-L：标签对齐（条件实验）

若论文要将差异归因于方向目标，应另做N-L本地控制实验，明确mappo_backend=local、ippo_backend=local，统一网络、概率分布、标签与优势标准化；两种作者PPO主基线保留GAE及优势标准化。先用3个开发种子验证，再冻结对齐对照，不只展示有利的一侧。该实验不属于主比较与单模块消融的60次训练，不默认扩大范围。

## 8. 独立评价与统计口径

### 8.1 评价时机、数量与成本

初版pilot使用6节点、每节点20回合；当前开发评价设置以运行说明和实际配置为准。正式在 0、5%、…、100% 的 21 个节点评价；前 20 个节点各 100 回合，final 200 回合。运行完成后以实际最后提交策略作为 B 节点策略。

节点使用预算不超过节点的最近已提交 Actor，禁止用越过节点后才得到的新策略。实现方式：下一轮可能越过节点时保留当前 Actor，在预算节点登记该快照；评价可延后执行，不能让结果反馈到训练。曲线不插值未来策略；AUC 用节点间左端已提交策略评价均值作矩形积分，末端 final 另报。报告这是固定网格近似，不是每轮精确积分。

各方法使用相同的预定 reset 种子表和源评价节点，以减少比较噪声；动作流按模型隔离，评价不得消耗训练 RNG。源节点评价可以共用 reset 集合，但不能将这些相关节点当作独立重复。final 使用另一套 reset 种子表。

源优化预算 B 不包含仅用于论文报告的独立评价，后者单独计账且不得用于训练接受或正式调参。按正式模板的评价密度，60次主比较与单模块消融的源评价为 `60*(20*100+200)*100=1320万` 团队步；N-A4/N-A5每加入一项各增10次训练及220万评价步，两项都加入共80次、1760万评价步。优化交互为实际任务数乘B，B需开发后冻结。再列目标和可选审计成本，不能把评价成本隐藏在“零成本”中。

### 8.2 必报指标

源学习曲线继续报告实际100步J与AUC/B，同时报告覆盖、距离、碰撞及成本。持续占位判断必须另看同一final策略的500步连续评价，报告mean_coverage、tail_coverage、tail_all_covered及mean_reward；单点coverage不足以支持保持覆盖。定义、CSV字段与诊断限制统一见[训练指标与调参说明](训练指标与调参说明.md)。

### 8.3 独立重复与不确定性

先对每个训练种子的评价回合求均值，再跨 10 个训练种子报告均值、标准差和 95% bootstrap 区间。方法差异按相同训练种子配对 bootstrap；同时给出每个种子的点，不能把 200 个评价回合称为 200 个训练种子。

预先将源 AUC/B 和 final J 列为主要结果；覆盖、碰撞及成本为解释指标。区间默认为逐比较区间，不是多个算法/规模同时覆盖的区间。若报告多项显著性检验，应事先指定比较集合并作多重比较校正。数据不支持差异时报告不确定，不能把“未显著”写成“证明等价”。

失败、NaN、预算耗尽、未达阈值均保留。运行错误可修复后按新代码版本重跑受影响的预定集合，但不能默默删掉失败种子或反复重试到成功。中断恢复只到完成轮次边界，额外采集但未提交的步数单列；正式训练不按评价表现提前停止。

## 9. 预期论文图表与结果解释

基本输出为一张源训练总览、一张迁移总览及 CSV；论文排版时再导出所需独立面板。

| 结果 | 内容 | 能支持的结论 |
|---|---|---|
| 源训练总览 | 4 方法回报曲线、覆盖、碰撞；单模块消融、检查成本和可选拟合敏感性 | 效率/性能与成本的具体取舍 |
| 正式方法表 | 6 个主条件及预定的N-A4/N-A5扩展：final J、AUC、覆盖、碰撞、耗时及区间 | 同源预算比较，失败种子数一并列出 |
| 迁移总览与表 | 4 方法×4 个规模的回报、距离、覆盖和碰撞 | 固定本地输入协议下的冻结迁移表现 |
| 可选审计表 | 旧/新回报差区间、检查决定、改善/退化/不确定 | 被抽取轮次的检查作用，不冒充全程精确真值 |

若 ours 与 sampled 相同，报告未发现解析项训练收益；若去检查更好，报告检查成本超过已观察收益；若缩短拟合不降性能，报告计算冗余；若源性能好而迁移下降，报告分布变化的限制。不要为了维持预期而改换主指标。
