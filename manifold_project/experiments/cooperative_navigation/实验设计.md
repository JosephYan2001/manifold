# 合作导航：实验设计与结论边界

更新：2026-09-22。本环境当前任务以“首次同时全覆盖即完成”为准，替代此前持续占位定义。命令与候选配置仅在[运行说明](实验运行说明.md)维护，结果见[当前实验判断](results/当前实验判断.md)。正式参数尚未冻结。

## 1. 研究问题

成对协作已经提示：方向估计改善不必然转化为训练优势，检查可能消耗交互而未体现收益，拟合预算可能有冗余。导航进一步在部分观测、多步动力学下检验这些问题，核心论文目标仍包括冻结Actor的零样本规模迁移。

| 问题 | 主要证据 | 不足以支持结论 |
|---|---|---|
| 相同源预算下是否更有效率 | 成功率曲线、success_AUC、final成功率与完成步数 | 训练回报更高或更新轮数更多 |
| 解析二次项是否有效 | ours与sampled单因素比较 | 不同loss绝对值 |
| 检查是否值得成本 | 单模块消融、检查账目与独立评价 | 检查通过即宣称真实不退化 |
| 拟合是否有冗余 | 拟合预算敏感性、KL与任务表现、耗时 | KL小就证明任务更好 |
| 零样本迁移是否更优 | 同一final Actor在N=3/4/6/8与各基线同规模比较 | 输入维度相同或跨规模原始奖励差 |

## 2. 共同任务协议

| 项目 | 规定 |
|---|---|
| 环境 | MPE2 Simple Spread，锁定mpe2==1.1.1 |
| 源规模 | 4机器人、4地标 |
| 观测 | 最近2机器人、2地标；数量限制，不是感知半径 |
| 动作 | 原生5个离散力方向动作，continuous_actions=False |
| 成功 | 同一时刻每个地标到最近机器人的距离严格小于0.1 |
| 结束 | 首次全覆盖立即success；500步仍未成功为deadline失败 |
| 初始已覆盖/最后一步成功 | 分别为0步成功/500步成功；成功优先 |
| 覆盖匹配 | 不要求机器人与地标一对一；不是各地标历史上曾被访问即可 |
| 物理 | 原生重置、碰撞半径和动力学；curriculum=False、dynamic_rescaling=False |
| 随机执行 | 从策略概率采样；贪心只能作为另标诊断 |
| 折扣 | gamma=.99，训练与评价一致 |

原生单机器人半径为0.15；覆盖阈值0.1与碰撞判据不是同一量。最优路径是否能在期限完成取决于具体场景，本次旧策略200场景诊断支持500步作为开发候选，不能证明所有随机场景均可达。

原生环境的提前结束开关保持关闭，由统一Navigation适配器在step后实施上述目标。末步奖励保留，成功之后不再采动作或累计奖励；不修改动力学。

所有方法对原生个体奖励取均值，local_ratio=.5：

```text
r_team,t = -0.5 * sum_k min_i ||p_i-l_k|| - |C_t|/N
J = sum_{t=0}^{L-1} gamma^t * r_team,t
```

C_t为唯一无序碰撞对，L是实际终止步数。本版不另加成功奖金或失败罚金，以便先隔离任务终点的改变。密集回报仍是训练目标，成功率是主要任务评价；两者并非完全等价，因此回报上升不能替代成功率证据。若后续调整奖励，须作为新协议统一全部算法并重新比较。

## 3. 终止、采样与CTDE

硬任务期限属于任务定义，成功和deadline失败都是真终止，bootstrap为0。训练批次配额用完属于外部采样截断，必须使用reset前实际最终观测的价值，并切断GAE递推。不能把两类超时混为一谈。[Gymnasium时间限制说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

Actor只接收本地历史8×(16观测＋5过去动作＋1有效位)和t/500，共177维；倒计时可由1−t/500得到。MAPPO及方向方法的集中Critic为64维原生state拼接＋时钟，共65维；IPPO Critic只读各自177维历史。Actor维度与N无关，目标环境只需Actor。

方向方法为128宽度两层tanh MLP并带beta混合；作者PPO保留LayerNorm、正交初始化和原生Categorical，当前作者MPE候选为Tanh、128宽度。公平性保证共同任务、信息、容量、源预算和评价，披露实现差异，不声称总参数数与优化器完全一致。eta与ppo_clip都影响幅度，但数值相同不代表等价约束。

## 4. 条件与单模块消融

| 条件 | 与完整方法的差异 |
|---|---|
| ours | 解析方向、Actor拟合、方向检查、回报接受/回退 |
| sampled | 仅解析二次项换为采样平方 |
| mappo | 作者PPO，集中Critic，无接受检查 |
| ippo | 作者PPO，本地Critic，无接受检查 |
| no_direction_check | 仅删除方向检查及其采样 |
| no_return_check | 删除回报接受/回退及其采样，采用首个有效候选 |
| fit_quarter | 仅Actor拟合epochs改为ceil(原值/4) |
| no_checks | 两检查联合消融；不替代单模块比较 |

sampled与消融继承选定ours参数，不各自调参。作者MAPPO/IPPO基于固定提交de66d7a4，算法代码仅改导入命名空间，任务适配见[模块说明](模块说明.md)。

## 5. 预算与阶段

一个联合动作推进计1团队步，不乘人数；源训练、方向检查、旧/新策略回报检查都计入B。独立报告评价和目标迁移另计实际成本。epoch复用不计交互，但报告优化次数和耗时。

每轮训练固定1600真实步；成功后开始下一场景直到配额，批末未完成片段bootstrap。方向检查8完整任务、每个回报策略8完整任务，最长500步，实际费用随首达时间变化：

| 分支 | 最大预留/轮 |
|---|---:|
| 完整方法，第一个候选 | 1600＋4000＋4000＋4000=13600 |
| 完整方法，两候选均检查 | 21600 |
| 方向拒绝 | 5600 |
| 去方向检查，第一个候选 | 9600 |
| 去回报检查 | 5600 |
| 作者PPO、no_checks | 1600 |

这是最大值，不是每轮固定费用。开始下一轮前预留首候选最大成本，回退前再次检查；不足则停止并报告unused_budget。中断未提交成本保守保留。不用相同轮数冒充相同预算。

当前顺序：已完成旧模型首达诊断 → seed40新任务MAPPO/IPPO与ours/no_checks各2000万步 → 必要时MC/GAE诊断 → 41/42开发复核 → 冻结参数、共同预算和正式种子100–109。2000万步不是收敛保证，也不因旧策略首达率高就跳过新协议公平对照。

## 6. 每个实验做什么、判断什么

| 编号 | 执行内容 | 主要输出及预期判断 |
|---|---|---|
| N-C，必做 | ours、sampled、mappo、ippo，各10正式种子 | 成功率曲线/AUC、final成功率、截尾步数、碰撞和成本；检验效率或最终能力优势，不预定赢家 |
| N-A1，必做 | 复用ours vs sampled | 同种子主指标差值与方向/拟合诊断；无差异则不能声称解析项改善训练 |
| N-A2，必做 | ours vs no_direction_check | 拒绝率、费用、success_AUC；检验筛选收益是否抵偿检查成本 |
| N-A3，必做 | ours vs no_return_check | 接受率、实际任务回报差、独立成功率曲线；检验整个回报控制模块，不仅一个阈值 |
| N-A4，敏感性 | ours vs fit_quarter | 拟合KL、主任务表现、计算成本；近似表现需多种子支持，不凭单点判等效 |
| N-A5，联合消融 | ours与两单检查组及no_checks | 分析共同预算下两检查的综合影响；接受率高是定义，不是安全证据 |
| N-T，必做 | N-C的final冻结到N=3/4/6/8 | 同规模比较成功率、截尾步数、累计碰撞；直接检验零样本迁移优劣 |
| N-D，提出逐次保护主张时必做 | 训练前保存ours/no_return_check指定轮次首候选 | 独立配对回报差与检查决定；只反映抽取候选，不代表全程精确真值 |
| N-L，作方向目标归因时开展 | 两PPO显式local、标签/网络/标准化对齐 | 排除整算法实现差异；与作者PPO主基线分开报告 |

N-C四条件40次，N-A2/A3各新增10次，主比较与单模块共60次；N-A1复用。N-A4/A5各另加10次，是否正式纳入须冻结前确定。

N-A5的交互量可预先取success_AUC：I=两检查保留−仅方向保留−仅回报保留＋两项去掉，按训练种子给区间。源预算相同下采样用途不同，不能据此声称门槛的纯数学因果效应。

N-T固定任务期限500、原生奖励/动力学/重置、邻居数、时钟及策略执行方式，只改变N及地标数量。每模型每规模200场景，N=4复用源final。其他规模最多24000×500=1200万评价步，提前结束后据实统计。禁止目标微调、更新观测统计、按目标成绩选择best或调参；跨N原始团队奖励不能直接比较迁移优劣。

N-D预定第1/5/10/20个完成轮次的首候选，没有候选则记缺失。训练后旧/新各200独立场景，reset配对、动作流隔离；比较实际首达任务J。区间支持改善而被拒绝，可记录该候选的经验误拒绝证据；未经多重比较校正不作总体错误率保证。审计最多1600万步，实际早停计费。它检查J，不直接证明成功率保护。

## 7. 独立评价与统计

开发配置含0至100%每2.5%预算节点，共41个，每节点1024场景；正式模板21节点、前20各100、final200，冻结时统一确认。节点只用不超过节点的已提交Actor；success_AUC按左端矩形积分/B，final另外报告。评价不反馈训练接受。

主指标预定为final成功率与success_AUC；同时必报包含失败的截尾完成步数。成功任务平均步数作为辅助，必须与成功率一同报告，不能只挑成功回合。累计碰撞、路径长度、实际J、耗时和优化次数解释机制。

每训练种子先汇总评价场景，再跨训练种子均值/标准差/95%bootstrap；方法差值按种子配对。场景数量不等于训练种子数量，单种子只作开发。区间跨0不证明等效，多比较需预定集合并校正。失败、NaN、未达阈值和未收敛如实保留，不重试到出现有利成绩。

旧持续任务训练产物已清理，仅保留旧策略首达诊断及来源记录，不能与新首达重训结果混合排名。工程验证不证明学习收敛；若去检查更好或迁移下降，应据实报告，不事后改换指标维护预期。
