# 协作导航：当前实验判断

更新：2026-09-20。旧有限时域结果、模型和详细判断已按用户要求清理，范围见[结果索引](README.md)。当前还没有新持续任务协议的训练结果，因此暂无算法排名、收敛或零样本迁移结论。

研究目标为持续导航并保持覆盖。下一步按相同持续协议、相同预算和seed40，从头训练MAPPO、IPPO、no_checks多步回报和no_checks GAE，每组2000万源团队步；之后用同一final策略进行500步连续评价。

当前MAPPO和IPPO均已接入同一作者实现，二者共用Actor及优化设置，Critic分别读取集中状态和本地历史。短程测试验证训练、各自bootstrap、CPU/CUDA恢复与冻结执行，不构成性能、收敛或迁移优势证据；Critic输入维度及参数量差异须在论文报告。

先核对学习曲线、平均覆盖、后半段覆盖与全覆盖时间比例，再决定是否延长预算或调整机制。协议修正本身不能证明性能改善；no_checks的成绩也不能记为完整ours的成绩。形成论文结论还需独立训练种子、公平对照及后续冻结迁移评价。

具体设置与命令见[实验运行说明](../实验运行说明.md)，指标含义见[训练指标与调参说明](../训练指标与调参说明.md)。
