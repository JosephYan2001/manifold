## 方法与恢复语义

新运行保存 `semantics_version=method-gates-v2`。历史 condition 名保留用于路径与采样种子兼容，损失和门控读取独立字段。有效配置逐轮写入 events.jsonl，并写入训练记录/summary。

未受影响的旧AN可继续通过公共入口恢复；历史checkpoint配置不偷偷迁移。旧SA若曾关闭任一检查，或旧DA声明关闭回报检查，则公共恢复/扩预算拒绝继续，因为其实际旧行为与修正后的声明不同。这些结果仍作为历史证据保留，应另开新实验验证修正方法。

## 只读探针与快照

新配置字段：

- `direction_diagnostic_rounds`：预定1起始训练轮次列表，默认空列表，不新增环境交互。
- `direction_diagnostic_episodes`：每个探针独立旧策略回合数，默认16。
- `save_direction_snapshots`：是否同时保存快照，默认false；只在上述预定节点生效。

源训练预算保持原定义，探针成本单列 `diagnostic_steps`，并保存在 `direction_probe_ledger.jsonl`。中断时未完成探针按预留上限计费；恢复不删除这些成本，扩预算继承此前诊断成本。固定源预算下，启用探针会增加真实总交互与运行时间，不能把它隐藏为零成本。

首次新运行可以使用示例配置（不在已有2M/4M运行中途改配置）：

```powershell
python -m manifold_project.experiments --experiments N-C --profile pilot --methods AN --config manifold_project/experiments/configs/navigation/diagnosis/read_only_probe.json --budget 2000000 --seeds 40 --device cuda --output manifold_project/experiments/results/evidence/navigation/navigation_probe_20261014_v1 --allow-duplicate-openmp
```

此命令是可复盘完整训练的示例，不是当前必须追加的首选实验；当前先执行已有D1/D2。

快照在对应运行的 `direction_snapshots/round_XXXXXX.pt`。离线重放不采样、不优化：

```powershell
python -m manifold_project.experiments.cooperative_navigation.replay_direction --snapshot "<运行目录>/direction_snapshots/round_000001.pt" --allow-duplicate-openmp
```

方向拒绝时快照没有候选/目标；正常情况下保存首次候选，即使后续尝试被采用，也不把首次候选标成最终采用策略。重放采用显式数值容差；异构设备与依赖版本可能产生数值差异。

## 固定策略诊断的新增用法

原[D1/D2命令](续训结果与诊断执行清单.md)继续有效；新D1输出B/D/E与饱和指标，D2的目标KL改为FP64归一化复算。训练优化目标仍使用原精度与原公式。

若需要逐优化步观察D2，在原命令末尾追加 `--fit-trace-every-updates 1`，并使用新输出目录。每步重算整批及验证指标会增加计算时间，不增加环境交互。最佳候选仍只按epoch边界的训练目标KL选择，不按评价回报选择。

N×U最小矩阵示例：

```powershell
$checkpoint = "manifold_project/experiments/results/evidence/navigation/navigation_diagnosis_20261012_4m_s40_v1/an_base/N-C_source_learning/full/AN_s40/checkpoints/final.pt"
python -m manifold_project.experiments.cooperative_navigation.diagnose --mode direction --checkpoint "$checkpoint" --output manifold_project/experiments/results/evidence/navigation/navigation_nxu_20261014_v1 --seeds 40 --sample-sizes 16 64 --direction-updates 128 512 --init-seeds 70 71 --validation-episodes 32 --evaluation-episodes 40 --fit-epochs 16 --target-kl 0.0001 --device cuda --allow-duplicate-openmp
```

同一数据种子的N=16数据是N=64的前缀；初始化种子70/71不改变采样数据和小批次随机数种子。U必须能被每epoch小批次数整除；上述四组分别为N16的16/64 epoch、N64的4/16 epoch。每个N/初始化单元保存独立结果。Actor拟合仍固定epoch，因此不同N的拟合更新次数不同；纯方向样本量结论优先看直接目标，不能把跨N Actor收益当作仅方向样本量效应。

共同KL在每个单元内匹配，不保证不同N/初始化单元的共同KL恰好相同。跨单元比较必须先核对实际KL；共同值过小时增加分辨率，不能强行作等步幅结论。
