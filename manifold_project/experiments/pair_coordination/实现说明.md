# 成对协作实现说明

本文描述当前可运行的一步任务。新冲突源和多步机制尚未实现；研究问题、目标族、验收条件和正式实验安排统一见[实验方案](../../docs/策略流形研究设计.实验方案.md)，跨环境模块边界见[项目总体架构](../../docs/项目总体架构.md)。启动和调参见[实验运行说明](实验运行说明.md)。

## 任务与数据

[PairConfig 和 PairCoordinationEnv](envs/pair_coordination.py) 定义任务：每回合独立抽取 n 个机器人的类型；每个机器人只根据自身类型选择动作 0/1，分别对应数学动作 −1/+1。联合动作获得一个团队奖励，随后终止。

\[
R=\sum_i b_{X_i}a_i+\frac{\rho}{n-1}\sum_{i<j}C_{X_iX_j}a_i a_j.
\]

[源配置](configs/pair_source.json) 当前为 n=4、p=(0.6,0.4)、b=(−0.2,0.3)、rho=0.7、C=[[1,−0.5],[−0.5,1]]。配置检查类型分布、对称交互矩阵及有限参数，并提供奖励绝对上界。修改源时必须重新核对这些量。

- reset() 抽取类型；reset(types=...) 仅供明确标记的固定事件诊断。
- step(actions) 计分并结束回合，下一次动作前必须重新 reset。
- state() 返回全队类型，供集中基线或诊断使用；Actor 和方向函数仍只读取自身类型。
- reward()/reward_batch() 只计分，不推进环境。

sample_episodes() 复制冻结策略，使用独立的类型与动作随机流。概率表形状为 (类型数,2)，每行严格为正且和为 1。N 个完整团队回合产生：

| 字段 | 形状 | 含义 |
|---|---|---|
| local_types | (N,n) | 各机器人的本地类型 |
| actions | (N,n) | 实际动作 |
| old_probs | (N,n,2) | 冻结 Actor 的动作概率 |
| team_rewards | (N,) | 团队奖励 |
| weights | (N,n) | 每条机器人记录权重 1/(Nn) |

一个回合内的机器人记录相关，划分数据和估计不确定性时必须保留回合分组。当前没有时间维度，也没有多步自举标签。

## 模型与更新流程

| 模块 | 实现位置 | 职责 |
|---|---|---|
| Actor、方向类型表 | [actor.py](models/actor.py)、[direction.py](models/direction.py) | 为每个类型保存一个可训练标量 |
| Actor、方向 MLP | [mlp.py](models/mlp.py)、[torch_models.py](models/torch_models.py) | 类型独热输入，经可配置宽度/深度的 tanh 网络输出一个标量；训练为 float64 |
| 集中基线 | [critic.py](models/critic.py)、[labels.py](training/labels.py) | 按全队类型组合拟合条件均值，构造冻结标签 |
| 方向损失 | [direction_loss.py](training/direction_loss.py)、[torch_fit.py](training/torch_fit.py) | 解析 Fisher 或采样平方目标；完整训练使用 PyTorch Adam |
| Actor 拟合 | [actor_fit.py](training/actor_fit.py) | 从旧 Actor 副本拟合固定指数目标 |
| 检查 | [acceptance.py](training/acceptance.py) | 独立方向检查及候选回报检查 |
| 控制器 | [runner.py](training/runner.py)、[config.py](training/config.py)、[plan.py](training/plan.py) | 冻结快照、采样、更新、费用和提交顺序 |
| 直接 PG | [policy_gradient.py](training/policy_gradient.py) | 每批新数据执行一次 on-policy Adam 更新 |
| 日志与保存 | [logging.py](training/logging.py)、[checkpoints.py](training/checkpoints.py) | 日志流、best/final 和恢复状态 |

Actor 输出 \(p(1|x)=\beta/2+(1-\beta)\sigma(z_x)\)，另一动作概率为 1−p；因此每个动作至少有 beta/2 的概率。方向输出 \(q(x)=(-t_x,t_x)\)，其中 \(t_x=Q_{\max}\tanh(z_x)\)，保证零和及幅度界。二者参数独立。

baseline=zero 时标签为团队奖励 R。baseline=table 时，每轮先用额外独立源数据拟合集中类型表，再冻结并构造 R−V(H)；表值裁剪到奖励界，未观测组合填零。它不是 Critic 神经网络，没有 Critic 学习率，也没有软更新或按回合交叉拟合。

完整方向方法的一轮为：

1. 冻结旧 Actor，采集源训练回合，固定旧概率与标签。
2. 更新方向函数，随后冻结候选方向。
3. 采集独立源回合进行方向检查。
4. 方向通过后构造指数目标，从同一个旧 Actor 副本拟合每个候选。
5. 分别为旧 Actor 和候选 Actor 采集独立回合进行回报检查；接受后提交候选，否则保留旧 Actor。

direction 模式只学习固定 Actor 处的方向；policy 模式执行多轮策略更新。去方向检查取消该步骤的采样与筛选；去回报检查直接提交首个有效候选。PG 不学习方向、不执行两项检查，Adam 状态跨轮保留。

令 \(S=e_U-\mu_x\)、\(F=\operatorname{Diag}(\mu_x)-\mu_x\mu_x^\top\)，方向损失为

\[
\widehat L_{\mathrm{an}}
=\frac1{Nn}\sum_{j,i}\left[q_{j,i}^{\top}F_{j,i}q_{j,i}
-2\widehat A_jS_{j,i}^{\top}q_{j,i}\right].
\]

sampled 仅把二次项替换为 \((S^\top q)^2\)。旧概率、score 和标签不接收梯度。Actor 目标为

\[
\widetilde\mu_\eta(u|x)
=\frac{\mu(u|x)\exp(\eta q_u(x))}
{\sum_v\mu(v|x)\exp(\eta q_v(x))}.
\]

拟合最小化训练类型频率加权的前向 KL \(D_{\mathrm{KL}}(\widetilde\mu_\eta\Vert\pi_\theta)\)。指数目标可能低于 Actor 的 beta/2 下限，因此充分优化也可能存在不可实现残差。

empirical 检查要求独立样本均值 >0；hoeffding 要求均值减置信半径 >0，并按 alpha/(rounds×(1+attempts)) 分配单次风险。前者没有后者的置信保证；后者依赖有效标签界、回合独立性及正确的重复检验分配。

## 精确诊断与指标

[exact_pair.py](evaluation/exact_pair.py) 枚举正概率类型与联合动作，默认上限为 100 万事件。默认四人二类型任务有 256 个联合事件。解析函数 closed_form_local_direction() 提供独立核对：

\[
g(x)=b_x+\rho\sum_y p_yC_{xy}\overline a_y,\qquad
v^{\mathrm{loc}}(x)=(-g(x),g(x)),\quad
\overline a_y=\mu(1|y)-\mu(0|y).
\]

在 iid 类型、共享本地策略及当前归一化完全图奖励下，

\[
J/n=\sum_xp_xb_x\overline a_x+
\frac\rho2\sum_{x,y}p_xp_yC_{xy}\overline a_x\overline a_y.
\]

因此只改变人数时，任何固定策略的人均回报不变。这是任务结构控制，不能当作算法的迁移优势。此解析式不适用于任意交互图、相关类型或尚未实现的多步任务。

| 日志字段 | 含义与使用边界 |
|---|---|
| expected_return | 精确平均团队回报；不是成功率。跨人数比较还需查看人均回报 |
| loss | 有限训练批次上的方向目标，可以为负；AN/SA 损失不能直接排名 |
| direction_error | 同一冻结 Actor 处的真实方向 Fisher 加权平方误差 |
| score | 总体变分分数；同一 Actor 下与方向误差对应，不是实际回报下界 |
| fit_initial_kl、fit_kl | 候选拟合前后的经验 KL；不代表全输入一致误差 |
| mean、radius、lower_confidence_bound | 检查均值、半径和均值减半径 |
| decision_value、threshold、accepted | 实际检查值、阈值和接受决定 |
| information_gap | 完整信息参考与本地方向的一阶差距，不是最优策略回报差 |
| amplitude_fraction | 最大方向幅度/Q_max；接近 1 表示触及容量限制 |
| target_min_probability | 指数目标最小概率，用于核对 Actor 概率下限 |
| source_episodes | 全部训练、基线与检查累计源团队回合数 |
| std_across_seeds | 独立种子间标准差；单种子为 null，不可据此声称稳定 |

真实量用于诊断，训练梯度与接受决定使用源样本。现有 best 归档使用精确源回报，见运行说明中的选模限制。不同轮次的 Actor 不同，方向误差和 score 无须跨轮单调。

## 输出模块

[套件入口](run_experiments.py) 串联训练与机制模块，[reporting.py](experiments/reporting.py) 汇总 CSV，[plotting.py](experiments/plotting.py) 生成套件总览。[plot_training.py](analysis/plot_training.py) 读取训练日志生成轮次总览或详细图，不重新训练。

[evaluate.py](evaluate.py) 只加载冻结 Actor 或匹配的 Actor/方向快照。类型词表必须与模型一致；人数可以变化。方向指标必须绑定训练该方向时的旧 Actor，不能用最终 Actor 搭配旧方向。

[visualization/render.py](visualization/render.py) 展示单回合奖励分解。[tests/](tests/) 核对任务计分、数学恒等式、更新、日志和恢复；既有测试通过不表示新冲突源或多步协议已实现。
