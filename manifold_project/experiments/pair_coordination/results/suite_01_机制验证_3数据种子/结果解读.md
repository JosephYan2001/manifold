# 本次机制实验：CSV 怎么读，结果说明什么

维护说明：本报告描述最初的 pilot 机制结果，保留当时的数值与统计口径。后续算法比较和消融已完成，见[结果目录索引](../结果目录索引.md)。新的机制确认与检查重复实验命令见[论文补充运行说明](../../论文补充实验运行说明.md)。

对应目录：suite_01_机制验证_3数据种子。配置：pilot，独立数据种子 40、41、42。P-M1、P-M2、P-M3、P-M4、P-H 全部完成。

本次只做机制实验，没有做完整算法比较 P-C 或消融训练 P-A。因此这些表不能回答“完整方法是否胜过 PG”，也不应出现整套训练的 learning_curves.csv。

## 1. 先分清两类文件

- records.csv：一行对应一次具体计算或一次数据集上的结果，用于追查细节。
- summary.csv：将同一条件的独立数据集汇总；一行对应一个条件下的一个指标。
- P-M2、P-M4 是确定性计算，没有随机数据集汇总，因此只有 records.csv。

优先看 P-M1/summary.csv、P-M2/records.csv、P-M3/records.csv、P-M4/records.csv、P-H/summary.csv。不要一开始就逐列阅读所有原始记录。

summary.csv 的通用读法：先看条件列和 metric，再看 mean。

| 列 | 含义 |
|---|---|
| metric | 当前这一行汇总哪个指标 |
| count | 汇总了多少个独立数据集，本次为 3；不是每个数据集的回合数 |
| mean | metric 指定指标的平均值 |
| std | 三次结果的样本标准差，反映波动 |
| ci_low / ci_high | 对这三次结果做 bootstrap 得到的 95% 区间端点 |

本次只有 3 个独立数据集，这些区间只能作试运行描述，不能据此宣称稳定或显著优越。summary 的区间也不是训练中 Hoeffding 接受检查的置信半径。

本目录的旧 P-H summary 仍是当时的 bootstrap 区间；当前代码的新 P-H 运行改用 Wilson 95% 二项比例区间，不会因代码升级自动重算本目录。新 P-M1 运行另提供 paired_summary.csv，本目录尚无该文件。

## 2. P-M1：哪一种损失学出的方向更准确？

打开 [P-M1/summary.csv](P-M1/summary.csv)，先筛选 metric=direction_error。这个误差越小越好。

| 条件列 | 含义 |
|---|---|
| actor_id=0 | 均匀策略，两种类型选择 +1 的概率都是 0.5 |
| actor_id=1 | 偏置策略，两种类型选择 +1 的概率分别为 0.2、0.8 |
| label=return | 用采样团队回报作训练标签 |
| label=exact_advantage | 用精确团队优势作标签，仅属于机制分析 |
| sample_size | 一次方向学习使用多少个独立源回合 |
| method=analytic / sampled | 解析 Fisher 二次项 / 采样动作平方项 |

本次 actor_id=1、label=return 的平均方向误差：

| 源回合数 | 解析项 analytic | 采样项 sampled |
|---|---:|---:|
| 128 | 0.00240887 | 0.00415853 |
| 512 | 0.000290106 | 0.000816645 |
| 2048 | 0.000163627 | 0.000350105 |

读法：例如最后一行表示，用 2048 回合学习偏置策略处的方向时，三个数据集上的误差均值分别约为 0.000164 和 0.000350。这组条件下解析项更准确。

不能推广为“解析项总是更好”。同一个偏置策略若使用精确优势，N=128 时解析项/采样项均值约为 0.00245725/0.00199470，N=512 时约为 0.000242055/0.000194412，都是采样项更低；到 N=2048 才是解析项更低。

均匀策略的几组结果完全相同也不是重复写错。当前二动作、零和方向 q=(-t,t) 下，均匀策略的采样平方项和解析二次项都等于 t²；同时零动作均值使联合类型条件下的期望奖励为零，因此这里的精确优势标签恰好等于原始回报标签。

其余列先这样理解：score 是在同一冻结策略处的一阶方向分数，正数表示一阶改进信号，不保证有限步策略回报一定提高；training_loss 是各自优化目标，不能跨不同目标按绝对大小排名。dataset_sha256 用于核对共用数据，q0/q1 是学得方向的两个类型参数，初读可跳过。

## 3. P-M2：方向给出的目标，actor 能不能实现？

打开 [P-M2/records.csv](P-M2/records.csv)。一行表示某个步幅、某个 actor 类，在指定更新次数后的拟合结果。

| 列 | 含义 |
|---|---|
| eta | 将方向转成指数目标的步幅 |
| actor_class=table | 每种类型可以分别调整动作概率 |
| actor_class=tied_logit | 两种类型强制共用一个动作概率参数，表达能力受限 |
| updates | 已进行多少次 actor 拟合更新 |
| target_gain | 精确指数目标相对旧策略的回报增量 |
| actor_gain | 拟合后的实际 actor 相对旧策略的回报增量 |
| fit_kl | actor 与目标的总体前向 KL，越接近 0 越贴合目标 |
| best_class_kl | 该 actor 类在概率限制下最佳可达参考的 KL |
| optimization_excess_kl | fit_kl 减去该参考：仍未优化到位的部分 |

固定 eta=0.1、updates=512：

| actor 类 | 目标回报增量 | 实际回报增量 | 拟合 KL |
|---|---:|---:|---:|
| 自由表格 | 0.02459894 | 0.02459894 | 约 4.34×10^-17，数值上为零 |
| 共用参数 | 0.02459894 | 约 1.57×10^-12，几乎为零 | 0.000299895 |

这组结果说明：自由表格基本实现了目标；受限 actor 已达到自身最佳拟合参考（多余优化误差近零），但表达能力限制使它几乎得不到目标增益。不能把后者解释成“继续增加更新次数就能解决”。

较少更新时，actor_gain 偶尔比 target_gain 更大，也不代表拟合更准确。KL 拟合并不约束实际回报必须低于目标回报；偏离目标可能偶然获得更高或更低回报，仍应看 fit_kl。

target_difference_quotient 是 target_gain/eta；exact_derivative 是起点的精确一阶导数。本次导数为 0.24，eta=0.01 时差商约 0.240604，步幅增大后差商偏离，反映有限步的高阶项。

类似 4e-17 表示 4×10^-17，即极小数。KL 理论上非负；本表少数约 -1e-17 的值来自浮点舍入，可按零理解，原始数值无需修改。

## 4. P-M3：环境改变后，同一个源方向还准确吗？

打开 [P-M3/records.csv](P-M3/records.csv)。一行对应一个冻结源方向、一个目标配置，没有在目标环境重新训练。

| 列 | 含义 |
|---|---|
| target | source 为源；agents_* 改人数；composition_* 改类型 0 概率；strength_* 改交互强度 |
| source_error | 学得方向与源真实方向的误差 |
| target_error | 同一学得方向与目标真实方向的误差 |
| direction_shift | 源/目标真实方向之间的 Fisher 加权平方距离 |
| transport_bound | 用源误差、覆盖系数与真实偏移计算的目标误差上界 |
| bound_holds | 检查目标误差上界及机制偏移上界是否在数值容差内成立 |

例如 seed=40：

| 配置 | 目标方向误差 | 真实方向偏移 | 目标误差上界 |
|---|---:|---:|---:|
| 源环境 | 0.000231051 | 0 | 0.000231051 |
| 只改为 2/6/8 人 | 均为 0.000231051 | 均为 0 | 均为 0.000231051 |
| 类型 0 概率改为 0.3 | 0.00147016 | 0.00254016 | 0.00497140 |
| 交互强度改为 0 | 0.07187854 | 0.06547968 | 0.07348997 |

本次全部 27 条记录的 bound_holds 都为 True：所测试配置满足数值界检查。这不是由 27 个结果证明一般定理，而是对实现和这些实例的核验。

人数不变性来自当前 iid 类型和归一化完全图；改变组成/强度会改变真实方向，源学得方向在目标上可能不再准确。不能把只改人数的结果当作一般复杂环境的泛化保证。

coverage_kappa 是目标/源类型概率比的最大值；neighbor_variation 是加权邻居组成测度的 L1 变化量；shift_bound 是机制推导的真实偏移上界；mechanism_transport_bound 是进一步代入该上界后的目标误差界。team_return 与 return_per_agent 属于冻结策略的回报，和方向误差不是同一个指标。

## 5. P-M4：为什么一阶方向为零，仍可能有改进？

打开 [P-M4/records.csv](P-M4/records.csv)。这是确定性数学核验，不是训练曲线。

| 列 | 含义 |
|---|---|
| epsilon | 两名机器人同时增加选择 +1 的概率 |
| direction_max_abs | 起点真实一阶方向的最大绝对分量 |
| actual_gain / expected_gain | 实际精确回报增量 / 理论值 4*epsilon² |
| identity_holds | 零方向和二阶增益关系是否成立 |

本次 epsilon=0.01、0.05、0.1，对应收益增量 0.0004、0.01、0.04；一阶方向均为零，三条核验都为 True。

含义：一阶方向只描述起点附近的线性变化，可能看不到纯粹依靠共同改变才出现的二阶收益。这是在验证方法边界，不是算法失败测试未通过。

## 6. P-H：检查规则会不会放错、拦错？

打开 [P-H/summary.csv](P-H/summary.csv)，先筛选 metric=accepted。此时 mean 是接受比例，不是回报。

| 条件/指标 | 含义 |
|---|---|
| kind=direction | 检查固定方向的一阶分数是否为正 |
| kind=return | 检查固定候选相对旧策略的回报改善 |
| truth_class=1 / 0 / -1 | 精确真值为正 / 零 / 负 |
| metric=accepted | 是否接受的平均值，即接受比例 |
| metric=false_accept | 真值非正却被接受的比例 |
| metric=false_reject | 真值为正却被拒绝的比例 |
| mode=empirical / hoeffding | 样本均值判断 / 减去保守置信半径后判断 |

固定 kind=return、sample_size=2048，三个独立重复的结果是：

| 候选真值 | 经验规则接受次数 | Hoeffding 接受次数 |
|---|---:|---:|
| 真正改善 | 3/3 | 0/3 |
| 零改善 | 2/3 | 0/3 |
| 真正退化 | 2/3 | 0/3 |

这说明本次检查设置存在明显取舍：经验规则放行了改善，也出现误接受；Hoeffding 更保守，本次所有条件下均未接受，也就拒绝了真实改善。不能把“从不接受”解释为训练效果更好。

2/3 只是这三个重复中发生两次，不是已可靠估计真实总体误接受率为 66.7%；也不能从这次小规模试验推断样本增加会使误接受率变高。

注意 records.csv 和 summary.csv 的 mean 不是一个东西：原始表的 mean 是这一批检查样本的平均统计量；汇总表的 mean 是 metric 指定的布尔指标平均值。原始表中 empirical 的 decision_value=mean，Hoeffding 的 decision_value=mean-radius，只有判断值大于 0 才接受。

原始表的 alpha 为分配给单次检查的错误预算；evaluation_batch_id 用来确认两规则共用同一批数据；两规则的 evaluation_episodes 不应重复相加。

## 7. 这次可以写出的简短结论

1. 在偏置策略、回报标签的三个样本量上，解析方向目标的平均误差更低；其他标签条件并不都如此。
2. 自由 actor 能充分拟合指数目标；受限 actor 存在表达残差，增加优化次数不能消除它。
3. 当前模型中仅人数变化不改变方向；组成与强度变化产生偏移，所测运输界均通过核验。
4. 二阶反例按预期成立。
5. 当前 Hoeffding 设置过于保守以至全部拒绝，经验规则则存在误接受，后续需结合源预算调整和增加独立重复。

这些是机制试运行结果，不能用三个数据集宣布方法普遍优越。算法比较和消融的开发实验此后已完成；当前待补的是新种子的正式比较、20 数据集方向估计与运输，以及每条件 200 次检查诊断，参见上方论文补充运行说明。
