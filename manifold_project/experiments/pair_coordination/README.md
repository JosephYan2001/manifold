# 成对协作

本环境承担可精确计算的机制核验：本地方向、方向估计、Actor 拟合、检查规则，以及覆盖与方向偏移。研究安排统一见[实验方案](../../docs/策略流形研究设计.实验方案.md)，项目分层见[总体架构](../../docs/项目总体架构.md)。

当前代码实现一步二动作任务；新方案的冲突源、多步机制及相应协议验收尚未完成。现有 P-C/P-A/P-M*/P-H 是旧接口编号，不能直接当作 R1-P 系列已实现，也不需要重跑旧大套件。

| 文档 | 内容 |
|---|---|
| [实现说明](实现说明.md) | 已实现任务、数据、模型、更新顺序、模块与指标 |
| [实验运行说明](实验运行说明.md) | 命令、配置用途、预算、调参、输出和恢复 |
| [保留数据说明](results/README.md) | 现存机制核对记录的用途 |

在包含 manifold_project 的仓库根目录，可先查看当前套件计划：

~~~powershell
python -m manifold_project.experiments.pair_coordination.run_experiments --profile smoke --experiments all --dry-run
~~~

该命令不训练、不生成结果。正式研究的目标、参数和启动条件只在总实验方案维护。
