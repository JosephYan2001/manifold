# 导航连续采样异常诊断

本批异常的直接证据是训练场景始终不重置，机器人在无边界空间中长期远离目标，造成训练状态和奖励尺度漂移。此前将“采样截断仍有后续价值”实现为“只有成功才能重置”，混淆了价值目标与采样组织。这是采样设计问题，不能先归因于预算不足，也不能据此判断 AN 或 MAPPO 的一般能力。

## 为什么出现这个量级

当前原生 simple_spread 没有把机器人限制在初始方框内。本项目关闭动态显示缩放，物理位置仍可以持续增大。距离奖励是各目标到最近机器人的距离之和的负值；本项目按 local_ratio=0.5 混合碰撞项，并取机器人奖励均值。对四人任务，无碰撞时每步团队奖励等于负的两倍目标平均最近距离。[MPE2 奖励定义](https://mpe2.farama.org/main/environments/simple_spread/)

gamma=0.99 时，200 步折扣权重之和约为 86.60。段回报 −3249 对应折扣加权步均奖励约 −37.52；这与远离目标的物理状态相符。这里的 segment_J 每段重新累计，并未把一万多步的历史总回报误当成当前 200 步回报。

无限延续带来两项直接问题：早期错误运动可把后续训练起点带到很远的位置；初始场景长期不更新，学习数据分布与每次从新场景启动的独立评价脱节。即使 gamma 很小，采样器仍在对很晚的状态持续更新策略，不能据“折扣回报有限”认定这种训练数据组织合理。

## Critic 与 PPO 能判断什么

MAPPO 的 critic_mse 是反归一化到原奖励尺度后的 MSE，不是作者 PPO 实际优化的 ValueNorm 损失。第 71 轮解释方差约 0.996，说明它能解释当前自举标签的大部分变化；不能凭 MSE 数值大认定归一化失效，也不能据此证明它估计了真实价值。标签本身还依赖自举。

AN 的解释方差接近零、原尺度误差极大，表明它的价值拟合也未跟上漂移后的标签。调整学习率、奖励缩放或 Critic 结构可能是后续问题，但应先排除共同采样缺陷，再用正常场景分布判断。

用户给出的第 57–61 轮 KL 为约 0.019–0.026，clip fraction 为约 0.15–0.22；仅凭这几个值不能确定 PPO 更新爆炸。源码与数值核对未发现跨段 GAE 使用下一场景代替末状态的问题，带非平凡 ValueNorm 统计的边界测试也纳入验证。

MAPPO 最近的独立源监控回报约 −203.09，与同轮训练段约 −3212.91 不处于同一场景分布；不能直接拼成一条曲线。AN 最终独立评价为 0/20 成功。两者尚未提供导航任务学好的证据。

## 修正后的统一采样协议

使用 navigation-success-v3，四组共同采用以下流程，奖励、动作、网络与学习率保持本轮配置：

1. 每条采样通道每轮取得 200 个真实联合环境步，轨迹可跨轮延续。
2. 首次同时覆盖全部目标时 terminated=true，后续价值为零，然后重置。
3. 未成功但连续采样累计达到 train_reset_horizon=1000 时，按外部采样限制重置。该边界 terminated=false、truncated=true，价值目标使用重置前的末状态，GAE 不跨新场景连接。
4. 重置后补齐本轮采样额度。1000 步不是任务截止时间，不增加失败罚分，不加入时间输入。
5. 评估仍在独立场景观察最多 1000 步；未成功记观察截尾，报告真实奖励，不添加 Critic 预测。

这是[Gymnasium 时间限制语义](https://gymnasium.farama.org/v0.26.3/tutorials/handling_time_limits/)允许的“外部截断后重置并自举”。自举仍是近似，不意味着截断后的长期行为已经得到真实数据验证。1000 步为当前共同采样上限，不声称是最优取值。

新增逐轮显示与 CSV 指标：步均奖励、段末目标距离、机器人最大位置半径、轨迹最大年龄、外部重置次数及 Critic 解释方差。事件账本区分外部重置与真正完成任务。

验证结果：109 项现有及新增测试通过，包括中途外部重置、重置前末状态自举、真终止零自举、待重置边界精确恢复，以及非平凡 ValueNorm 统计下的逐段 GAE。AN 和 MAPPO-E 各做了 6 轮 CUDA 短程检查，使用缩小网络与优化次数、2 条轨迹及实际 200/1000 步采样设置；轨迹年龄均为 200、400、600、800、1000、200，第 5 轮触发两次外部重置，价值误差保持有限。这验证采样通路，不是修正后 200 万步性能结果。临时验证输出已自动清理。

当前异常运行应保留作诊断；若仍运行，可在终端停止，不继续靠扩大预算延续。本版从头训练并使用新目录，命令统一见[导航手册](../../cooperative_navigation/README.md)。先复验 AN 无检查与 MAPPO-E 的状态、奖励和源学习，再决定是否扩展检查组；修正采样不等于已经证明收敛。
