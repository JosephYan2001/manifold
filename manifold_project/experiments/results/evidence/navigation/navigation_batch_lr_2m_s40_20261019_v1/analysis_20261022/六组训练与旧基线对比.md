# 六组导航训练与旧基线对比

2026-10-22。六组 N16/N32/N64 × 固定/线性衰减学习率均已完成约 2M 源交互及 100 场景终点评价。**用户观察到的学习退步有数据支持：六组的同场景源监控曲线及全程回报面积均低于 2026-10-10 的 an_base；六组最终均为 0/100 成功。** N16 衰减与 N32 固定是本轮表现较好的两个设置，尚未恢复旧基线的学习速度和回报水平。

六组内部的采样量与学习率对照成立，但它们相对旧基线还同时改变了方向训练预算和 Actor 候选选择。旧基线每轮方向训练 16 epoch，新六组只有 4 epoch。**本日补充归因审查后，撤回自动追加两组 500k 的建议：缺少对照不能成为不断追加训练的理由。** 首轮更新尺度分叉、后期 Critic 数值失效、教师收益未确认应分别处理，不能把本轮结果直接解释为学习率衰减失效、最佳候选有害，或代码修复导致性能下降。当前决策以第 6 节为准。

## 1. 完成情况与可比口径

六组同为训练种子 40，源规模 4，8 帧实体历史，成功即结束，训练回合最多 400 步，评价最多 1,000 步。均使用 final.pt 和随机动作评价。记录核对包括：

- 六组初始 Actor、Critic 哈希完全一致；同一 N 的 fixed/linear 首轮训练回报、初始目标 KL、所选拟合 KL 和实际策略 KL 完全一致。
- 六组训练代码指纹均为 `ca7918b4b3a3b072b4d7e08879254ef5b4e3265c5171e2a7e755f1a01b2d075b`；旧基线为 `657d55d101acf8a9a750476ff9ea4785e2462bf41234a517bc651ae32c17adf7`。所记录的 NumPy、Torch、MPE2 等依赖版本相同。
- 日志中的学习率逐轮符合已声明的源交互日程，并与传给 Actor 拟合器的学习率一致。最后一轮的学习率高于 3e-5 是因为该轮开始时尚未达到 2M，不是日程失效。
- 所选候选的整批训练 KL 不劣于零更新候选；六次最终评价审计均完成，每次 100,000 步、训练和优化次数为零，检查点哈希与文件一致。
- 六组实际源交互合计 **11,980,529** 步，最终评价合计 **600,000** 步，总计 **12,580,529** 步；诊断额外采样为零。本次分析没有新增环境交互。

必须区分三种评价：

| 口径 | 场景 | 用途 |
|---|---|---|
| source-grid | 所有组共用 8 个监控场景，按固定预算节点评价 | 本报告比较学习曲线和预算归一化 AUC 的主口径 |
| source-final | 另外 8 个终点监控场景 | summary.json 的 J；不能把曲线最末跳变当成同一组场景上的突然改善 |
| final_evaluation | 新六组共用 20262000–20262099；旧基线为 1000000–1000019 | 终点策略表现；新旧集合不同，不能做场景配对差值 |

旧图最后从约 −105.70 跳到 −93.63，包含了 source-grid 切换到 source-final 的场景变化。重新绘图保留 source-grid 的 31 个节点，避免这个跳变影响直观判断。即使去掉这一步，旧基线仍明显领先。

## 2. 回报与任务成功

回报越高越好。AUC 按训练器的左端点阶梯积分除以 2M 复算，表示整段预算内的平均监控回报；不是成功率 AUC，也不是独立训练重复。

| 运行 | 训练轮数 | 最后 source-grid 回报 | 监控回报 AUC | final 平均回报 | 成功数 |
|---|---:|---:|---:|---:|---:|
| 旧 an_base | 272 | −105.70 | **−123.68** | −104.27 | 0/20，旧场景 |
| N16 fixed | 272 | −145.95 | −157.05 | −147.89 | 0/100 |
| N16 linear | 272 | −124.43 | −147.88 | −117.56 | 0/100 |
| N32 fixed | 136 | −123.76 | −145.29 | **−115.61** | 0/100 |
| N32 linear | 136 | −125.84 | −147.99 | −127.27 | 0/100 |
| N64 fixed | 68 | −137.98 | −160.17 | −147.80 | 0/100 |
| N64 linear | 68 | −142.91 | −164.93 | −145.48 | 0/100 |

新旧独立终点回报只是描述性并列；更可比的源监控数据同样显示旧基线占优。所有终点策略都没有解决全覆盖任务，旧基线也只是回报更好，不能称为已学会导航协作。

本轮六个终点策略面对相同 100 个场景。按完整场景配对，重采样 20,000 次，随机种子 20261022，衰减减固定的差值为：

| 对比 | 平均回报差 | 95% 配对 percentile bootstrap 区间 |
|---|---:|---|
| N16 linear − fixed | **+30.33** | [+25.89, +34.91] |
| N32 linear − fixed | **−11.66** | [−15.07, −8.41] |
| N64 linear − fixed | +2.32 | [−2.13, +6.86] |

衰减对 N16 有正向效果，在 N32 下为负，N64 尚未辨认出明确差异。不能把“初期大、后期小是经典做法”直接推广为当前任务上的普遍优势。这些区间只描述固定策略的场景不确定性，未做多重比较校正；全套只有一个共同训练种子，不构成跨训练种子的算法结论。

## 3. 旧基线与新六组之间缺了一个对照

最贴近旧基线的是 N16 fixed，但二者仍有以下差别：

| 设置 | 旧 an_base | 新 N16 fixed |
|---|---|---|
| 每轮采样回合 | 16 | 16 |
| 方向 epoch | **16** | **4** |
| 每轮方向优化步 | **128** | **32** |
| 全程方向优化步 | **34,816** | **8,704** |
| Actor 学习率 | 3e-4 | 3e-4 |
| Actor epoch | 16 | 16 |
| Actor 提交规则 | 最后候选 | 最佳训练 KL，含零更新 |
| 源监控预算 | 256,000 | 256,000 |
| 训练代码 | 历史版本 | 修复、候选选择与日程接入后的版本 |

奖励、网络宽度、历史长度、η、Critic 学习率和 epoch 等主要设置没有变化。六组的 4 epoch 来自此前 N64/U128 的短训练配置；它是明确的实验选择，但不是旧 an_base 的方向预算。六组总方向优化次数相同，只有旧基线的四分之一。

因此，本轮能回答新配置内部的 N 与日程取舍，不能回答相对原始方案“只改采样量与学习率”是否改善。此前方案没有保留当前代码下的 16 epoch 对照，这是研究设计缺口；在现有数据中不能补写其效果，也不因此自动安排补跑。

也不能直接得出“方向训练越多越好”：历史 N16/64 epoch 的 an_direction64 最终为 −105.22，没有明显超过 16 epoch 的 −104.27；历史 N64/16 epoch 的 an_batch64 为 −102.63。旧 16 epoch 应保留为历史配置参照，不能把增加预算本身当修复，也不能把 N64 本身判为不可用。

## 4. 教师目标更小，Actor 通常已经拟合了大部分目标

旧基线与新 N16 首轮训练回报同为 −180.3891；旧首轮目标到旧 Actor 的 KL 约 5.51e-4，新首轮约 7.87e-6，相差约 70 倍。其余冻结对象没有保存成完整历史目标包，因此这不是同目标重放，但目标尺度的差异在训练初期就已出现。

| 运行 | 每轮目标到旧 Actor KL 中位数 | 所选残差/初始残差中位数 | 零更新轮数 |
|---|---:|---:|---:|
| 旧 an_base | 1.08e-4 | 不按新口径复算 | 无新选择器 |
| N16 fixed | 8.16e-6 | 5.63% | 19/272 |
| N16 linear | 1.22e-5 | 3.96% | 14/272 |
| N32 fixed | 2.96e-5 | 16.34% | 1/136 |
| N32 linear | 2.21e-5 | 12.43% | 1/136 |
| N64 fixed | 1.41e-5 | 23.35% | 12/68 |
| N64 linear | 1.34e-5 | 18.65% | 0/68 |

旧目标 KL 为历史 FP32 字段，新值为归一化 FP64，数量级比较不能冒充精确同口径匹配。新六组内部口径一致。残差比例是同一批次上实际拟合误差的比例，不是执行收益或“方向实现百分比”的保证。

新 N16 两组多数轮次已把训练目标残差降到很低；N64 fixed 的实现损耗仍更大，最后四分之一训练的残差比例均值约 45%，不能宣称 Actor 环节已全部解决。另一方面，N64 linear 的 68 轮全部更新了 Actor，整体仍弱；“最佳选择器拒绝更新太多”解释不了所有组。

旧 Actor 的最终训练批次策略熵约 1.561，新六组为 1.594–1.607，接近五动作均匀策略的 log(5)=1.609。结合目标和实际策略 KL，支持“当前训练中的策略偏移较小”这一描述；低熵或大 KL 本身不保证更好的方向或更高回报。

新六组有效方向触边占比均为零。N64 个别轮次有原始 tanh 饱和，但不能据此认定整个方向输出普遍被 q_bound 卡住。

## 5. 四组 Critic 在多数轮次输出近似常数

以下读取完整训练批次、Critic 拟合后的统计；“近似常数”按该批次价值预测方差小于 1e-6 计数，是描述性阈值，不是算法门控。

| 运行 | 近似常数轮数 | 最后一轮解释方差 | 最后一轮预测方差 |
|---|---:|---:|---:|
| N16 fixed | 227/272 | 约 0 | 1.20e-13 |
| N16 linear | 0/272 | **0.420** | 37.43 |
| N32 fixed | 45/136 | **0.306** | 47.19 |
| N32 linear | 115/136 | 约 0 | 5.68e-14 |
| N64 fixed | 57/68 | 约 0 | 1.47e-13 |
| N64 linear | 53/68 | 约 0 | 1.02e-12 |

四组最终价值目标仍有约 282–1,194 的方差，而预测方差已接近零。因此这比单独看到 EV 接近零更直接地支持“在所观测训练状态上，Critic 几乎只给出一个常数”。N16 linear 与 N32 fixed 后期出现了状态区分能力，同时回报较好。

这并未证明 Critic 是唯一根因，也未确定因果顺序：Actor 更新改变访问状态，可能反过来改变 Critic 的学习难度；方向 epoch 改变也会影响后续数据。旧基线没有相同的整批 Critic 方差日志，不能补写为“旧 Critic 一定正常”。

价值目标归一化仍值得后续单独研究，但不能从这些日志直接断定它必然修复问题，或把奖励归一化、初始化与方向预算一起加入而失去归因能力。

### 5.1 不增加环境交互的参数审查

新增 [离线审查程序](audit_mechanism.py)直接读取七个 final.pt，将 4,096 个共同的合成输入送入 Critic，在 CPU/FP64 下检查敏感性。输入按环境的 24 维状态字段排列：机器人位置、速度、目标位置；位置独立取 [-1,1]，下表速度为零，另保存速度也取 [-1,1] 的敏感性探针。**这些不是历史训练状态或新评价回合，不能用来测价值预测准确率或替代训练分布上的证据。**

| 模型 | 合成输入上的价值输出标准差 | 第二层 tanh 局部导数 < 1e-6 的比例 |
|---|---:|---:|
| 旧 an_base | 9.517 | 71.68% |
| N16 fixed | 9.30e-8 | 100% |
| N16 linear | 4.829 | 95.66% |
| N32 fixed | 5.066 | 84.43% |
| N32 linear | 2.37e-7 | 100% |
| N64 fixed | 3.16e-7 | 100% |
| N64 linear | 2.15e-7 | 100% |

四个近似常数模型的第二层 tanh 严重饱和，状态变化难以传到输出；与完整训练批次上接近零的预测方差相互印证。旧模型也有大量饱和单元，但保留了输出变化，不能把“出现饱和单元”本身等同于模型失效。

代码中 AN 使用原始尺度价值目标、两层 tanh、MSE 和 Critic 学习率 1e-3；公共配置中的 PPO 价值归一化不作用于这条 AN 路径。新 N16 首轮的整批目标均值约 −217.69，初始预测均值约 −0.051，Critic 裁剪前梯度范数均值约 1,361.93。**“在较大负目标下先学成近常数，隐藏层饱和后难以恢复状态区分”是与代码和权重相容的具体机制假设；尚未通过干预证明目标尺度是其原因，也未证明价值归一化一定能修复它。**

新增环境步、优化步均为零。原检查点与日志的 14 个文件哈希前后相同；完整输入定义、两套探针结果和时间顺序见 [mechanism_audit.json](mechanism_audit.json)。

## 6. 归因与收敛决策（替代此前追加两组短训练的建议）

**后续状态：本节提出的 Critic 固定数据尺度诊断已完成，见[实测分析](../../critic_scale_probe_20261022_v1/analysis_20261022/Critic尺度诊断结果分析.md)。** 归一化降低饱和并改善训练拟合，独立回合预测未改善，两个起点均未通过预定筛选；不能据此将尺度处理接入主训练。以下保留该实验前的归因与动机，当前行动以实测报告为准。

### 6.1 分开回答“新配置退步”和“AN 原本就弱”

**新配置退步的最早可见分叉在方向目标，而不是后期 Actor 选择或 Critic 坍缩。** 旧 an_base 与新 N16 首轮训练回报、Critic 最后小批 MSE/解释方差记录一致；目标 KL 已相差约 70 倍，且这个量在拟合和选择 Actor 之前计算。方向预算 128→32 次更新是最直接的配置嫌疑。历史版本到当前版本的相关代码差异中，AN 的解析 Fisher 目标、标签计算和 Critic 损失形式未发生对应的数学修改；但没有完整旧批次与方向快照，仍不能宣称做了精确反事实重放。

Critic 问题出现得更晚：新 N16 fixed 首次整批预测方差 < 1e-6 是 round 36、262,400 源步。旧基线也经历过价值拟合低谷，公共旧口径的末小批 EV 在 round 20 约 2e-6、round 40 回到约 0.436。末小批数值不替代整批统计，却足以反驳“旧 Critic 始终健康、新代码才引入全部问题”。

因此，现有证据支持的时间顺序是：**先出现不同大小的教师目标；随后不同策略/数据轨迹中，部分 Critic 长期失去状态区分能力。** “小更新使策略停滞，停滞与价值失效互相强化”仍是反馈机制假设，不能把时间先后当成完整因果证明。

**AN 原本就弱则不能靠恢复 16 epoch 解释。** 旧基线本身 0/20 成功、平均监控覆盖率约 3.46%，只是距离/回报有所改善。恢复旧回报不等于解决协作导航，也不等于证明方向网络有增量价值。

### 6.2 不再把 Actor 实现损耗当统一主因

当前 N16 两组所选训练残差中位数仅为初始的约 5.6%/4.0%，却仍然没有解决任务；N64 linear 每轮都更新 Actor，表现仍差。这不支持继续用“没有拟合好”或“选回旧策略太多”解释所有失败。

此前 E1 的数据种子 43/44 来自旧 A0 的 round 545，而六组从随机初始化开始。训练后期的微小固定目标上，小学习率和最佳候选能够降低拟合误差，不能据此推出它们就是从头训练的性能修复方案。教师收益封顶复核中，两个平均增益为 +0.077、+0.202，区间均跨零，见[原复核](../../teacher_return_review_20261018_v1/analysis_20261018/固定教师复核分析.md)。这不是证明教师无效，但正收益没有被确认，不能把“更忠实实现教师”当成必然提高回报。

当前优先级应是**价值估计—优势标签—方向目标这一上游链路**。对非终止转移，若 V(s)≈c，TD 残差变为 r−(1−γ)c，丢失了价值预测随状态变化的部分；这会改变当前 GAE 标签的性质，但不等于标签全部错误或方向必然反向。原始标签、每轮重新初始化的方向网络及有限拟合预算之间是否产生有用信号，现有训练 B 分数不能单独回答。

### 6.3 排查方式需要改什么

此前排查有三处推进过快：把工程验收与局部代理指标改善推进为整体性能预期；把训练后期的固定目标结论外推到冷启动；在方向预算降为四分之一、未保留连接基线的情况下铺开六组。修复与记录仍有价值，但它们没有构成“性能瓶颈已解除”的证据链。

**停止追加 Actor 学习率、N、方向 epoch 的训练矩阵；撤回两组 500k 作为默认下一步的安排。** 16 epoch/last 是历史参照，不是已经验证的修复方案。也不重复 43/44 的教师评价来等待显著结果，不把补齐 MAPPO 评价当新的前置门槛。

下一项若开展实验，只保留一个问题：**现有 Critic 的常数输出是否由价值拟合的数值过程产生，能否通过单一尺度处理干预恢复独立数据上的状态区分？** 先做固定数据的机制验证，冻结原始价值目标与数据划分，保持模型、优化预算和初始实际价值预测可比，仅比较现有拟合与价值目标尺度处理；Actor、方向网络及任务奖励不动。误差必须换回同一原始量纲，验证数据不参与挑模型。没有完整批次包时，不能冒充历史重放；至多新建一次数据包并明确计费。本机当前没有历史 fixed_targets 包，本项尚未实施。

这是优先检验的假设，不是已经决定加入主算法的补丁。应在执行前固定一个预算及结束规则：若只改善训练误差、验证状态区分没有恢复，则不进入完整训练，也不自动转去扫描更多归一化/激活/初始化组合；若改善可重复，再用一个受控短训练检验标签、教师和回报是否随之改善。**只有价值指标改善而教师/执行仍无增量，就应否定“Critic 是足够解释”，转而评估方向网络这条路线的必要性，不能继续用 Actor 调参维护原假设。**

当前只能判定现有导航实现与配置未证明学习效率优势；不能据单训练种子否定全部理论，也不能承诺再加一个技巧就能追上 MAPPO。
