## 3. 对当前研究判断的影响

**每组 2M 是有依据的诊断预算。** 历史 MAPPO 已在相近任务协议、400 步采样、8 帧实体历史下学到有效行为。因此，若新 AN 六组到 2M 仍几乎均匀随机、任务收益没有改善，不能仅用“2M 太短”解释；应承认这轮采样量和学习率干预不足以解决问题。

**不能从这条记录直接断言 MAPPO 的方向更准确。** MAPPO 每轮 N16，PPO 10 epoch；使用作者更新流程、优势归一化、ValueNorm、价值裁剪与 Huber 损失。它与 AN 的目标构造、优化和价值学习不同。历史源码指纹为 `6820ad62ce5888c0aa7c56306f12ea1f5b078fd1ec7daa54dff976c9531826ab`，也不同于修复后的 AN 代码。相同交互预算并不保证相同优化成本或相同初始化参数。

训练日志中，策略熵从 1.603 降到 0.502，记录的 Critic 解释方差从 0.282 到 0.961，与任务表现改善相伴。这支持“该运行确实发生了学习”的描述，但 MAPPO 与 AN 的价值目标和统计实现不同，不能据此确定 Critic 是唯一原因。配置记录 Actor 学习率 3e-4；这也不是 AN 使用衰减必然有效的证据。

历史 AN 2M 的回报约 −102.6～−105.2、各 0/20（见[导航证据索引](../../../README.md)），与本运行有明显数值差距；但它们是修复前的历史结果，不能冒充即将执行的六组新 AN 结果。近期 AN 四格只有约 0.48M，亦不能把其终点当作同预算 2M 比较。

## 4. 如何接入下一轮六组实验

以[六组实验方案](../../../../../notes/导航采样量与学习率六组实验方案_20261019.md)为唯一执行定义，六组 AN 训练矩阵不变。本轮增加一次**冻结历史 MAPPO `final.pt` 的参照评价**：

- 与六组 AN 共用 100 个预定场景 20262000–20262099、随机动作评价和 1,000 步上限；不使用历史 20 场景的均值直接构造配对差值。
- 固定模型、历史输入与推理语义；先确认加载和推理兼容性，保存 checkpoint 哈希。禁止静默替换网络、归一化状态或用 best.pt 代替 final.pt。
- 不进行 PPO 更新，不新增训练数据。最多增加 100,000 评价步，六组 AN 加最终评价的 12.6M 上限相应扩为 **12.7M**；历史已消耗的 2,012,874 步另列，不重复算作本轮新增成本。
- 报告全部六组 AN 与该固定 MAPPO 策略的场景配对差值及任务指标。这比较的是已得到的策略，不等于同版本、多训练种子的算法优越性结论。
- 如果旧 checkpoint 的推理语义无法可靠恢复，保留历史参照并说明缺口；不自动把本轮扩成 MAPPO 重训。

**上述 100 场景 MAPPO 评价尚未执行。** 2026-10-19 补充：公共冻结评价入口已通过该历史 checkpoint 的 CPU 加载与 3 步工程检查，参数及文件哈希不变；这不构成完整评价结果。运行命令见[六组训练与冻结评价说明](../../../../../../configs/navigation/batch_lr_2m/README.md)。不将历史 −54.32 或 35% 设为新场景的硬性通过线。新 AN 即使相对自身有改善，也要明确是否仍明显落后于这个参照；两者回答不同问题。
